### R1 查重池口径统一（阻塞项，已给出方案）

**问题实证**：`atomic_store` L114 full_hash 查重走 `memory_organize.load_memories()`（`memory_organize.py:239`）= 读 **jsonl 全量 320 条**（status 全 None，含 2 deleted + 37 precedent）。而真相源 DB `core_memory_card` 有 status 列（active 318 / deleted 2）。误用 jsonl 池 → 已删/已降级卡仍参与比对，且 jsonl 无 status 无法区分活性。

**方案：新增 `load_active_pool()` 作为唯一比对池来源。**

- 位置：`memory/memory_organize.py` 新增函数，复用其已有 `sqlite3` + `MEM_DIR` 能力（`_write_card_to_db` 已在用）。
- 签名与实现：

```python
def load_active_pool() -> list:
    """P0/full_hash 唯一比对池：DB status='active' AND tier='active'。
    2026-11-23 #30 R1：彻底替代 load_memories()（jsonl 全量）做查重池。
    返回 [{inst_id, summary, full_hash, dfcp_tag(dict)}...]，只取比对所需字段。"""
    import sqlite3 as _sq
    _db = os.path.join(MEM_DIR, "corpus_store.db")
    con = _sq.connect(f"file:{_db}?mode=ro", uri=True, timeout=5)
    con.row_factory = _sq.Row
    rows = con.execute(
        "SELECT inst_id, summary, full_hash, dfcp_tag, detail "
        "FROM core_memory_card WHERE status='active' AND tier='active'"
    ).fetchall()
    con.close()
    out = []
    for r in rows:
        d = dict(r)
        try:
            d["dfcp_tag"] = json.loads(d.get("dfcp_tag") or "{}")
        except ValueError:
            d["dfcp_tag"] = {}
        out.append(d)
    return out
```

- **改动点 1（full_hash 查重）**：`memory_organize.py:114`
  - 原：`if any(e.get("full_hash") == fh for e in load_memories()):`
  - 新：`if any(e.get("full_hash") == fh for e in load_active_pool()):`
  - 语义影响：deleted/precedent 卡的精确副本不再被拦——**正确**（已删/已降级的事实允许重新入库为新 active）。
- **改动点 2（P0 语义查重）**：见 §三 P0，同样用 `load_active_pool()`。
- **回归用例**：构造 deleted 卡（status='deleted'）与准新卡同 summary → 验证不被其拦截；构造 precedent 卡（tier='precedent'）与准新卡同 summary → 验证不误拦（可正常新建）。
- **注意**：`load_active_pool` 与 `memory_query.load_memories`（读 DB 但**只过滤 status 未过滤 tier**）口径差一层（tier）。查重池口径必须加 `tier='active'`，理由：precedent 是已降级的旧版本，不应拦住新写入。

```python
def read_card_detail(entry: dict, purpose: str) -> str | None:
    """#30 R4：统一 detail 读取，防 derived_only 泄露到业务层。
    purpose:
      'search' / 'reasoning' / 'display' → derived_only 卡返回 None（不暴露派生 detail）
      'dedupe' / 'audit' / 'governance'  → 返回完整 detail（查重/审计/治理需要原文）
    兼容：entry 可能来自 DB row(dict) 或 jsonl(dict)，dfcp_tag 已在 load 时反序列化为 dict。"""
    detail = entry.get("detail")
    if detail is None:
        return None
    tags = entry.get("dfcp_tag") or {}
    if isinstance(tags, str):          # 兜底：未反序列化
        try:
            tags = json.loads(tags)
        except ValueError:
            tags = {}
    if tags.get("derived_only") and purpose in ("search", "reasoning", "display"):
        return None
    return detail
```

### R6 入库进程生命周期（确认结论：短驻一次性进程）

**实证**：
1. `.codechat/settings.json` 的 PreCompact hook = `python memory_hook.py session --file ...` —— **每次 PreCompact 新起 Python 进程**。
2. `memory_hook add` 由主 AI 在会话中 `subprocess` 调用 —— **同样短驻**。
3. `embed_semantic._cache` 是**纯进程内 dict**（`embed_semantic.py:38`），无落盘。
4. `trace_embedding` 表实测仅 4 列 `(tid, ts, model, n_items)`——**审计元数据，不存向量**，无法"复用"。

**结论**：短驻进程 → **不能依赖进程内存缓存**。每次入库新进程，若不持久化，则每次付 1.32s 全池 warmup（280 条）。

**数据分析**：近 30 天入库 320 条，路径 A 297 条 / 路径 B 23 条；日级 2~78 条。PreCompact 每次会话触发一次，单次通常 1~数十条。

**方案对比**：

| 方案 | 每次入库冷启动 | 实现 | 结论 |
|---|---|---|---|
| A：每进程 warmup（不持久化） | 1.32s + 36ms | 最简，零新增存储 | 可接受（PreCompact 低频） |
| B：持久化向量表 | ~0ms | 新增表/文件 + 增量维护 + 失效同步 | 复杂，需处理卡删除/降级时向量失效 |
| **B'（采纳）：持久化向量缓存文件** | ~50ms（读文件） | `data/memory/summary_vec_cache.jsonl`（inst_id→vec）+ 按需增量 | 折中 |

**采纳 B'**（对短驻进程友好、实现简单、免新表）：

- 文件：`data/memory/summary_vec_cache.jsonl`，每行 `{"inst_id":..., "model":"bge-small-zh-v1.5-onnx-int8", "vec":[512 floats]}`。
- 加载：P0 前 `_load_vec_cache()` 读入内存 dict；与 `load_active_pool()` 的 inst_id 取交集，缺失的（新库/缓存失效）批量 `embed()` 补齐并回写。
- 失效：卡被 deleted/precedent 时其 inst_id 不在 active 池 → 自然排除（缓存可留作垃圾，定期清理）。
- 冷启动实测预期：读 280 行 jsonl (~280×512 floats) ≈ 数十 ms + 缺失补齐。
- **备选**：若嫌文件大，用 `.npz`（numpy 压缩）。段五编码时二选一，默认 jsonl（可读性优先）。
- **简化原则**：首版可先落 A（每进程 warmup 1.32s），B' 作为性能优化项。若段四实测 PreCompact 超 120s timeout 有风险再上 B'。**默认首版走 A，B' 留开关。**

if SUMMARY_EQUIV_MODE not in ("off", "dry-run", "on"):
    SUMMARY_EQUIV_MODE = "off"   # 非法值安全降级

**P0 内部分支逻辑**（伪代码）：

```python
def _p0_equiv_check(summary, pool, tag_derived):
    """返回 ('skip'|'pass', best_inst_id, best_sim, elapsed_ms)"""
    if SUMMARY_EQUIV_MODE == "off":
        return ("pass", None, 0.0, 0.0)          # 完全跳过，零开销
    t0 = time.perf_counter()
    try:
        q = embed_cached(summary)                 # 冷启动 miss 时 ~8.5ms
        # 池向量：优先 vec_cache，miss 批量 embed（见 R6）
        sims = pool_matrix @ q                    # 280 条矩阵乘 ~27ms
        idx = int(sims.argmax()); best = float(sims[idx])
    except Exception as e:                        # embed 加载/推理失败
        _log_gate("p0_unavailable", {"err": repr(e)[:200]})
        return ("pass", None, 0.0, 0.0)          # 降级放行，不阻断入库
    elapsed = (time.perf_counter() - t0) * 1000
    hit = best >= SUMMARY_EQUIV_THRESHOLD
    verdict = "skip" if hit else "pass"
    if SUMMARY_EQUIV_MODE == "dry-run":
        _log_gate("p0_equiv_dry", {...verdict/score...})   # 只记，不真的 skip
        return ("pass", pool[idx]["inst_id"], best, elapsed)  # dry-run 一律放行
    # on：真拦截
    if hit:
        _log_gate("skip_equivalent_derived", {
            "new_summary": summary[:120], "best_inst_id": pool[idx]["inst_id"],
            "best_sim": round(best,4), "elapsed_ms": round(elapsed,2)})
        return ("skip", pool[idx]["inst_id"], best, elapsed)
    return ("pass", pool[idx]["inst_id"], best, elapsed)
```
