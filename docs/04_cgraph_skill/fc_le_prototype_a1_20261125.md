# 元核思维 FCLe 原型 A1 对照实验记录

> 日期：2026-11-25　|　阶段：A1（非盲测，质量对齐验证）　|　结论：**质量合格，进入方案 Y 预演**

## 1. 背景与定义

**FCLe = Fixed-Framework（固定推理骨架）+ LLM-Embedded（语义推理主体仍是主模型）**

一句话：`run_skeleton` 只输出结构化思维框架、路由候选、节点清单，不做任何语义推理、不调 LLM；全部推演、打分、决策由主 AI 承接。

- 旧管线：每个节点单独起子 LLM（一次复杂 run 约 12 次 LLM 调用，数分钟~数十分钟）
- FCLe：骨架一次性给齐（0.1ms），主 AI 一条链跑完（仅自身 1 次推理）

## 2. 验证清单与结果

### 指标① 速度 —— 压倒性优势

| 项 | 耗时 |
|---|---|
| `run_skeleton` 纯数据生成（图热加载后）| 平均 **0.1ms** / 最大 0.2ms |
| 老管线同题（ab_result 存档 ms）| 291s / 441s |
| 目标 <100ms | ✅ 远超达标 |

### 指标② 质量对齐 —— 三道题结论打平

对照数据源：`logs/ab_result_*.jsonl` 老管线存档（question + path + answer + ms）。

| 题 | FCLe 结论 vs 老管线 | 差异程度 |
|---|---|---|
| 题1 记忆三级存储映射 | 完全一致（三层映射表 + repro_hint=derived）| 无差异 |
| 题2 本地部署 vs 云端 API | 核心洞察一一对应（成本差10倍/最弱环节/合规准入/路径非快照/退出成本不对称）| 极小 |
| 题3 AI客服内外双层防御 | 四条硬规则逐条对应（双轨熔断/跨边界三要素/证据等级/退出演练）| 极小 |

**路径不一致的根因（次要问题，非质量缺陷）：**
1. 老管线路径来自 **LLM 语义分类 + LLM 逐节点 deepen 动态演化**（如走 Bc/Fp/Fq/Fr/Gs/Ht/Iu/Iv 等风险/防御/刹停节点）
2. FCLe 纯关键词分类 + 图贪心（走 Bb/Cf/Cg/Di 等溯源/利益全景节点）
3. `mind_graph.json` 在 2026-11-25 19:44 被赫布更新，基线 ab_result 是 11-13 的，权重时间漂移

**结论：路径只是手段，三项核心裁决（结论/约束边界/关键洞察）全部对齐原管线，框架具备等价决策能力。**

### 指标③ 赫布取舍观测（原型不落地）

`hebb_placeholder = {ratio: null, edge_id: null}` 已占位。原型不更新权重。

- 短板2：本次是**有基线参考的非盲测**，存在轻微结果污染；Y 方案验证需安排一组**盲测样本**（提前封存、推理前看不到老答案）做兜底校验。

## 4. 方案 Y 定义（已确认）

> 保留 Router 分类头 + 节点全部 FCLe 化

| 组件 | 定义 |
|---|---|
| **Router** | 保留独立语义分类头（轻 LLM 分类），输出 depth、deepen_candidates，驱动 mind_graph 选路，**维持赫布权重更新回路**，保住自进化能力 |
| **业务节点**（Aa/Bb/Cf…Jw）| 不再单独起子 LLM，只输出固定思维框架；全部语义推演/权衡/收敛由**唯一主 AI** 完成 |
| **管线** | Router(轻LLM分类) → run_skeleton 输出节点框架 → 主 AI 一次性走完所有节点推理 → 推理后主 AI 输出 hebb_ratio 回填，更新边权重 |

**好处**：拿到 FCLe 秒级加速 + 判定稳定不跳标签，又保住图路由自进化，不废赫布回路。
