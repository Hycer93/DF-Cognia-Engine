# F20 权重层设计（design_f20_weight.md）

> 定稿：2026-11-16（用户三条裁决 + 晋升核对卡 fa1b5458 固化）。
> 前置：F00/F10/F40 最小闭环五场景实测通过（2026-11-16），四门槛三过一半过，
> 第四门槛（失败溯源）补课项纳入本设计。
> 层级：experiment 层（F 系），只读红线不变：不写卡/不挂簇/不改范式。

---

## 1. 定位

F20 = 分支赋权层。把 F10 发散的均匀权重（δ=0.1, w 全 1.1）替换为
**从库内记忆属性实时组合生成的复合权重**——top-K 从"候选集"变成"优先级排序"，
这是 F 系从链路校验器迈向推演器的第一步。

哲学基点（2026-11-15 用户裁决）：权重是推理与记忆组合生成的，不是训练产物。
F20 的组合公式只读库属性（置信/边类型/簇密度/时间戳），模型不参与、不自我修改。

## 2. 权重公式（两层结构，2026-11-16 用户裁决①）

```
w(branch) = (1 + δ_step)^β · C(conf) · F(fresh) · R(edge) · D(density)
```

| 因子 | 定义 | 裁决依据 |
|---|---|---|
| `δ_step` | **按推演距离衰减**（BFS 步数）：离锚越远天然降权，抑制无限长松散关联链 | 主衰减维度=步数；新鲜度**不混入 δ**，防"链长惩罚"与"时间衰减"混淆、消融难拆 |
| `β` | 指数旋钮，**人闸静态参数**（见 §3） | — |
| `C(conf)` | 置信乘子：L0=1.0 / L1=0.7 / L2=0.4（沿用 F00 分级） | — |
| `F(fresh)` | **独立新鲜度因子**，叠加在 C 旁边：近期裁决/事故/新归档卡权重高；陈旧考古卡缓慢滑降。半衰期默认 90d（与范式层 decay_period_days 对齐） | 裁决①：新鲜度单独做乘子 |
| `R(edge)` | 边类型乘子：relation 显式演化边=1.0；topic_links 弱时序边=0.5（沿用 F40 双边权重） | — |
| `D(density)` | 簇密度乘子 × **图谱债务软惩罚**（见 §4） | — |

## 3. β 三档位（2026-11-16 用户裁决②）

**规约一：β 是人闸静态参数，模型与推演脚本本身不能自主修改。**
**规约二：不开放连续自由调参，预置三个命名档位：**

| 档位 | β 值 | 语义 |
|---|---|---|
| `conservative` | 0.6 | 压制长尾分支，优先短、强链路 |
| `baseline` | 1.0 | 回归基线，**所有五场景回归必须跑此档**，对比漂移的锚点 |
| `exploratory` | 1.6 | 愿意给长链机会，适合探索场景 |

每轮推演日志必须归档所用档位（审计元信息）。

## 4. 图谱债务惩罚（2026-11-16 用户裁决③：软惩罚非硬截断）

```
D(density) = cluster_connectivity × (1 - debt_ratio × λ_debt)
```

- **债务定义**：簇内零锚卡 / hold 留置卡 / 未挂载孤立节点占簇内总卡比例
  （数据源：core_hold_pool + topic_links 缺挂统计，E7 P2 同源口径）
- **惩罚逻辑**：债务越高，密度项打折——只压优先级，**不删分支**
- **边界红线（用户原话约束）**：不能因为簇债务高屏蔽里面真实的因果链。
  topic_memory_ops 早期就是高债务簇，但恰恰藏着整套治理的核心因果。
  软降权，永不拦截。
- `λ_debt` 软惩罚系数：默认 0.5，消融扫描对象（见 §6）

## 5. 失败归因四类枚举（门槛四补课项，2026-11-16 用户裁决）

F40 失败不再只返回"无路径"，每条失败必须打枚举标签：

| 枚举 | 含义 | 判据 |
|---|---|---|
| `edge_coverage_gap` | 边覆盖缺口——库补债后可能变可解 | 目标可达锚的邻域但中间断链 |
| `sensitive_blocked` | 高敏拦截——防御性失败，正确行为 | 路径必须穿 sensitive_topics |
| `goal_isolated` | 目标真孤立——卡无任何有效边 | 目标节点度=0（双边合计） |
| `step_exhausted` | 步数耗尽——max_steps 内未达 | 有路径方向但超 12 步 |

**归因字段的三个去向**：① 每条推演链的审计元信息写日志；② 晨报直接展示；
③ 作为未来置信度修正的输入（如 `edge_coverage_gap` 高频出现 → 提示还债方向）。

## 6. 消融实验计划（每次只动一个变量，五场景回归）

| 轮次 | 固定 | 扫描 | 观察指标 |
|---|---|---|---|
| A1 | 其余全部 baseline | β ∈ {0.6, 1.0, 1.6} | 五场景判定翻转？top-3 排序漂移幅度 |
| A2 | β=baseline | λ_debt ∈ {0, 0.5, 1.0} | 高债务簇（memory_ops）分支排序变化；红线验证：债务=1.0 时核心因果链仍在 top-K |
| A3 | β=baseline, λ_debt=默认 | δ_step 衰减系数（步衰减斜率） | explore1 长链（9 卡）存活 vs 被压制 |
| A4 | 全默认 | F(fresh) 半衰期 {30d, 90d, 365d} | 考古卡（f4198bf7 类）滑降速率 |

每轮输出 `logs/f20_ablation_*.md`，PASS/FAIL + 排序快照，供人闸审阅。

## 7. 实现清单

1. `f20_weight.py`（eval/experiment/）：因子函数 + 组合公式 + 档位表；只读库
2. F10 接线：`f10_diverge` 的 δ 均匀赋权替换为 F20 调用（CONFIG 增 `beta_profile` 字段）
3. F40 补课：失败路径上收集四类归因判据，写入报告与 snapshot json
4. 审计元信息：snapshot json 增 `weight_factors` 块（各因子值+档位+归因枚举）
5. 回归：五场景 baseline 档全跑，与 2026-11-16 结果对照（判定不变为基线验收标准）

## 8. 红线（继承 + 新增）

- 继承：只读库；快照与报告为唯一落盘物；高敏簇默认过滤；relation 边永不裁剪
- 新增：β 档位表写死代码不可被运行时修改；债务惩罚永不升级为分支删除；
  消融必须固定 baseline 档跑回归锚点
## 9. 收尾裁决归档（2026-11-16 用户定案）

**并入 nightly**：挂主链尾部（T1 之后），归属 experiment，不升级进 core。
- 仅跑 baseline β=1.0 守卫基线；conservative/exploratory 档位保留，只在手动消融实验启用，夜间不跑。
- 基线 PASS/FAIL 翻转 → 晨报高亮告警（**⚠️ F20 基线异常**），但不阻塞 E 系 core 主链。
- 日志摘要纳入晨报（读 `logs/f20/guard_latest.json`）；完整链路快照保留独立目录 `logs/f20/nightly_<date>/`（每场景 md + snapshot json）。
- 守卫脚本 `eval/experiment/f20_nightly_guard.py` 吞错恒退出 0——experiment 层不惊扰主链步骤状态。
- 理由（用户原话）：它是认知图谱健康监控，值得每晚站岗；但它属于推演实验层，不能成为核心体检的阻塞门槛，和四层目录的划分保持一致。

**λ_debt 默认值锁定 0.5**：消融验证 λ=1.0 不会击穿 D 下限，但惩罚力度偏强，容易让中等债务簇里合理的次要因果链被过度压低；0.5 温和，既能把图谱债务反映到排序权重，又不会过度压制正在治理、逐步补边的成长型簇（典型 memory_ops）。后续若观察到大量低质量孤立分支频繁上浮，再单独开消融上调。

**配套夜间回归规约**：只校验基线链路可达性（判定）与排序相对位次是否稳定；权重具体数值允许小幅浮动，只要不发生链路出局、座次颠倒，不判定为故障。
- 位次校验的实现注记（2026-11-16 守卫调试发现）：F 因子改连续 age（`total_seconds/86400`，弃 `.days` 整数截断）+ minloop sort 次级键 `inst_id`——否则同权并列簇的次序由 DB 行序决定，跨日跳变会让位次校验随机抖动。同权并列时以短 id 字典序定序，属确定序非语义序。
