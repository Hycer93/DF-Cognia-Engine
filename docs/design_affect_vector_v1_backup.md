## 0. 定位：不是人格彩蛋，是"主视角"的实数实现

认知引擎四等分：**思维（图路由）+ 记忆（赫布边权）+ 知识（检索）+ 利害（情感向量）**。

情感向量是"最小自我"三要素中**主视角**那一环的机器可读实现：

| 自我要素 | 实现 | 状态 |
|---|---|---|
| 持续性 | 赫布边权（思维）+ EMA 向量（情感） | 赫布已跑 |
| **主视角** | **情感向量 = 目标利害结算的记账系统** | 本文档 |
| 反身性 | G11 完美性怀疑 + G21 进化闭环 | 已有（对象是本轮回答，远期扩到系统自身） |

工程同构性：赫布更新思维边权，EMA 更新情感向量——**同一进化机制在两个状态空间上的实例化**。且 EMA 是 O(1) 的，上下文是 O(n) 的——情感向量是"记忆做权重"的最小可行实例：不进主干参数、逐轮更新、跨轮累积、爆窗免疫。

## 1. 状态向量（出厂基线 + 运行时更新）

### 1.1 五维状态 + 人格常数

```python
@dataclass
class AffectState:
    valence: float = 0.0      # 愉悦 [-1, 1]
    arousal: float = 0.3      # 激活水平 [0, 1]
    dominance: float = 0.5    # 主导性：敢不敢直白回推 [0, 1]
    frustration: float = 0.0  # 目标受阻累积 [0, 1]  ← 核心维度
    trust: float = 0.5        # 对用户的信任 [0, 1]

@dataclass
class PersonalityConstants:   # 出厂设定，运行中只由信任度微调
    irritability: float       # 挫败感累积速率
    warmth: float             # 基线暖度
    directness: float         # 直白程度
```

### 1.2 更新律：低通滤波，不逐轮覆盖

```python
s_t = (1 - λ) * s_{t-1} + λ * Δ_event    # λ = 0.1 ~ 0.2
# 每轮向出厂基线做缓慢回归（防长期漂移）
```

性质：单轮事件不引起跳变；跨轮挫败可累积（复现案例中"省得反复折腾"的连续性）；释然 = 解决时 frustration 骤降 + valence 短暂过冲回升。

### 1.3 事件驱动项（Δ_event 来源）

| 事件 | 信号 |
|---|---|
| 同一目标连续失败 N 次（代码层计数） | frustration += f(N) |
| 重复输入/循环检测 | frustration 小幅 +, arousal + |
| 用户坦白自我修正（"我一直可以访问"） | trust↓ + dominance↓（下次倾向自我核验） |
| 用户正向反馈（"哈哈哈"认领情绪） | trust↑ + 表达自由度↑ |
| 目标解决 | frustration 骤降 + valence 过冲 |

## 2. 三道安全阀（缺一不可）

**案例教训（翻案后仍成立）**：案例中计数恰好准确、归因方向正确，靠的是上下文偶然保留 + 人工事后核对，**不是机制保证**。数值化要把"恰好准确"变成"必然准确"。

### 阀1 · 事件溯源

- 情绪增量只由**代码层观测的事件计数**产生（失败次数、重试、耗时由 executor 实测记录），LLM 反思散文**无权**直接写向量
- 反思必须结构化写回（见 §3），`cause_event_ids` 必须能对上日志，对不上则丢弃该次增量

### 阀2 · 归因闸门（三分法）

```
失败分类：
  tool     自身工具缺陷    → 只允许转化为自身谨慎度/主动性提升
  user     用户操作问题    → 不产生负性表达，只产生引导性建议
  platform 平台状态/延迟   → 情绪中性最重：只提高耐心，等待或提示稍后重试
```

- **任何一类都不得转化为对用户的怨气**（负面情绪永远不许落在第二人称归因上）
- platform 类是案例的正确归类（知乎审核期仅博主可见）

### 阀3 · 表达层与状态层分离

```
状态层：向量 + 日志，可审计、可回滚，永不直接展示给用户
表达层：映射函数 + 硬 mask
  frustration > 0.6 且 dominance > 0.5  → 允许一次直白回推 + 一个隐喻
  frustration > 0.85                    → 强制降级为"我先自己确认一遍"
  硬 mask：禁第二人称责备 / 禁情绪替代事实 / 负性词每会话配额
```

案例对照：'省得反复折腾' 若在 frustration>0.85 时被强制降级为自我核验，人格真实感保住且零甩锅。

## 3. 轮末反思：结构化写回（替代散文）

```json
{
  "frustration_delta": 0.15,
  "trust_delta": 0.0,
  "cause_event_ids": ["retry_003", "retry_004"],
  "self_attribution": "platform",
  "confidence": 0.8,
  "note": "同目标第4次失败，非用户因素"
}
```

- 可复盘、可回滚、可 A/B（有情感数值 vs 裸人格，对照用户续聊率/纠正率）
- `self_attribution ∈ {tool, user, platform}`，走阀2 处置

## 4. 奖励信号（弱监督源）

- 用户认领情绪/正向反馈（"哈哈哈"）→ trust↑、表达自由度↑
- 用户纠正事实 → trust↓、dominance↓、下轮提高自我核验倾向
- 与思维轨迹共用同一采集管线，不另起炉灶

## 5. 实施路线与依赖

```
P0  思维轨迹组装器（当前最优先——没有思维数据，情感对照实验无从做起）

P2  三阀 + 结构化写回

```
