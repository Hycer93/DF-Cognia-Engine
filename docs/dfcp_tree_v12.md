# DFCP 四维树初版定稿方案（v1.2，主AI×DS 两轮对撞 + 用户主张修正）

> 日期：2026-11-06。对撞记录：logs/ds_dfcp_tree_r1/r2.txt。数据基础：三源素材梳理（元核语料+S6池 48 条 / EHV 车载项目 38 条记忆 / BugAnalyst+本项目对话）。
> 用户原始主张：树应该深（一二三四级），分细→碎片化缓解→检索可控→整理容易。
> DS 检验结果：因果链三环全断，但**用户主张的合理内核（编码前缀=聚类先验）被第二轮挖掘采纳**。

## 一、最终架构：领域树 3 级结构 + L4 语义叶子，其余三树维持

```
领域树（唯一细化的树）
L1 域（5个，占编码位）─── 宏观投资/软件工程车载/AI认知工程/诊断复盘/元协作
 ├ L2 子域（≤8/域，占编码位）
 │   └ L3 场景（≤8/子域，占编码位）★设启用门槛
 │       └ L4+ [open_vocabulary] 语义叶子：不占编码位、不进结构判定、
 │           不参与编码匹配度，仅作检索语义扩展与整理聚类提示
```

**四维各树裁决：**

| 树 | 深度 | 裁决依据 |
|---|---|---|
| 领域树 | **3 级结构+语义叶子** | 主AI原草案（仅 L1+全开放）**过浅**——空置编码位=浪费最高权重项（编码匹配度 0.28-0.35）；用户主张四级结构**过深**——超判定三级档位+编码位硬上限 |
| 行为树 | L0-L9+B00 不动 | 已实证（mind_graph 边权账本），细化无收益 |
| 关联树 | 拓扑不分级 | 关联是边不是节点，分级违反语义 |
| 情感树 | 四子维不分级 | 情感是连续量，分级=离散化损失 |

## 二、L3 启用门槛（本轮对撞的核心定案）

**L3 场景级节点必须过回挂验证 ≥5 条摘要才启用**；未过门槛的节点自动降级为 L2+语义叶子（编码位保留）。三个论据汇聚到同一结论：

1. **档位成本**（DS 修正版）：L1-L3 判定各对应判定档位（嵌套三级），L3 若落 derived 重判档，单次成本是 L1 数倍——低密度节点撑不起这个成本
2. **簇素材条件风险**（DS 修正版）：细树不必然稀释簇（簇=embedding 语义聚类，树=导航编码结构，可分离——主AI 概念纠偏被采纳）；但低密度节点确实合并素材不足
3. **前缀先验增益**（用户主张的合理内核，DS 第二轮承认漏算）：同 L3 节点下两条摘要共享更长编码前缀（`001-01-03`）→ 聚类先验更强 → 阈值可收紧 → 合并更准。**单调增益，但只在密度够的节点成立**——与门槛条件同构

**净效应**：密度足够的节点，前缀先验增益>判定成本；低密度节点反之。门槛机制让每个 L3 节点自己证明值得启用。

## 四、编码与迁移条款

- **3+2+3 编码格式冻结**（专利 B 权利要求已写死，改格式=动权利要求+全库重编码，代价远大于改深度）
- L1-L3 占编码位，每级 ≤8 位；L4 起一律 `[open]` 不分配编码
- 迁移：旧数据保留原挂载，新数据按新结构挂，不强制重判——结构冻结+内容开放
- 双轨验证：L3 上线前用历史摘要回挂，<5 条的节点暂缓启用

## 五、立法三阀门（承接昨日裁决，不变）

1. 叶节点开放集（L4+ open_vocabulary，模型/社区可扩充，走 GOVERNANCE PR）
2. X2 协议化（模型可提议绕过节点→先例累积→节点修订，受治理的进化路径）
3. 双轨验证条款（结构化 vs 无结构持续对照，判负节点进 deprecation）

## 六、对撞裁决记录

- DS r1 抓出主AI草案实质缺陷：**编码位空置**（最高权重项只有 L1 可匹配）——主AI接受
- 主AI r2 抓出 DS 两个过度断言：误分藏深论（对 L4 不成立，撤回）、簇密度稀释论（结构断言撤回，降为条件风险）——DS 各让一半
- **用户主张的"编码前缀=聚类先验"增益被双方第二轮确认纳入**——用户直觉的合理内核最终进入方案（v1.2 收益账），虽然四级结构本身被否
- 分歧全收敛：DS 最终"方向未变，论证更硬"，主AI无异议点
