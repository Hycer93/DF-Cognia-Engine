# 可对账情绪记账系统（Auditable Affect Ledger v1.2）

> 状态：设计定稿（第六场 DS 攻防 6 轮 + 用户目的改写，2026-11-04）。v1 原稿备份：design_affect_vector_v1_backup.md
> 依赖：思维轨迹组装器（优先级仍在其后）。本版含外置熔断层+自主演化三层。
> 核心引用案例：`docs/case_study_403_emotion.md`（2026-11 知乎审核期事件，已人工核对翻案）。
> **系统目的（用户定案，最高层）**：本系统为**自主性**服务——出厂基线平平，随交互史漂移出慎重/保守/激进等策略配置，实现 AI 个体化。**不是拟人**（不是为了让 AI 成为人类——当前能力距人工智能很远；且即便是，也必须避免激进的 AI 疯子）。
> **主张（换名定案）**：对外是"可对账的情绪记账系统"，**不是**"更真的情绪"。措辞纪律：禁用"真实/真诚/有心/像人"，只用记账/可对账/结痂/降级级词汇。

## 0. 定位：自主性的实数实现（v1.2 目的改写）

**自主性 = 策略参数对交互历史的敏感性**——这是可测定义：出厂同基线的 N 个 AI 经历不同交互史后，人格常数与策略分布是否显著分叉。零分叉 = 零自主（每次都从头启动的出厂机）；有分叉 = 个体化。表达只是策略参数的读数，不是产品。

认知引擎五等分：**思维（图路由）+ 记忆（赫布边权）+ 知识（检索）+ 利害（情感向量）+ 安全（外置熔断）**。

情感向量是"最小自我"三要素中**主视角**那一环的机器可读实现：

| 自我要素 | 实现 | 状态 |
|---|---|---|
| 持续性 | 赫布边权（思维）+ EMA 向量（情感） | 赫布已跑 |
| **主视角** | **情感向量 = 目标利害结算的记账系统 → 自主演化的策略参数源** | 本文档 |
| 反身性 | G11 完美性怀疑 + G21 进化闭环 | 已有（对象是本轮回答，远期扩到系统自身） |

工程同构性：赫布更新思维边权，EMA 更新情感向量——**同一进化机制在两个状态空间上的实例化**。且 EMA 是 O(1) 的，上下文是 O(n) 的——情感向量是"记忆做权重"的最小可行实例：不进主干参数、逐轮更新、跨轮累积、爆窗免疫。

**两层实在性（第六场定案的层分离）**：
- **状态层**（本系统主体）：事件→EMA→向量，因果可重放（cause_event_ids 对日志）。实在性判据 = 状态确实驱动行为 + 因果可校准 + 表达不高于状态。**独立性检验实测前不得对外宣称状态层实在性**（DS 通过条件）。
- **信号层**（表达可信度）：接收方凭什么信你。costly signaling 射程专属此层——本系统的表达不承担"更真"的证明责任，只承担"不演没有的状态"。

**修正版定义（DS 收回"真实=不可控"后的定案）**：真实 = 一致性（表达↔状态）+ 事件因果校准（状态↔事件）——落在可验证性这个公共父集内。与可信（关系性担保）两轴不同向。本系统主张精确化定性："**外部压力触发、自主完成的精确化**"。

**目的改写对第六场战果的重新排序**：
- 外置熔断+判据外置：从补丁升为**核心架构件**（防激进AI疯子的兜底层）
- 缓变基线（人格常数随长期证据漂移）：从工程注释升为**系统主输出**（自主性的载体，见 §1.5 自主演化三层）
- 表达层全部争论（表演/伪善/信号可信）：降权为次要（表达=策略读数）
- 对账/结案记录：定位为 **operator 审计需求**，非用户关系修复需求
- P4 续聊率指标：**测错对象**——续聊率测用户喜好不测自主性；新增指标 = 策略分叉度（见 §8）

## 1. 状态向量（缓变基线 + 运行时更新）

### 1.1 六维状态 + 人格常数

```python
@dataclass
class AffectState:
    valence: float = 0.0          # 愉悦 [-1, 1]
    arousal: float = 0.3          # 激活水平 [0, 1]
    dominance: float = 0.5        # 主导性：敢不敢直白回推 [0, 1]
    frustration_task: float = 0.0 # 目标受阻累积（我的 KPI）[0, 1]  ← 慢通道
    frustration_stake: float = 0.0# 用户利害受损（你的损失）[0, 1]    ← 快通道
    trust: float = 0.5            # 对用户的信任 [0, 1]

@dataclass
class PersonalityConstants:   # 缓变基线（非固定出厂值）
    irritability: float       # 挫败感累积速率
    warmth: float             # 基线暖度（可被长期正向证据缓慢上调）
    directness: float         # 直白程度
```

**frustration 双分量（第六场修正，回应"指向错位"——"你是为我难受还是为你自己没干成难受"）**：
- `frustration_task`：任务受阻，由 executor 硬传感器驱动（失败次数/耗时/重试实测），走 EMA 慢通道（持续压力型累积）
- `frustration_stake`：用户利害受损，**仅由用户显式表达驱动**（"这 bug 害我加班到两点"），走快通道（事件脉冲型冲击）。注意：stake 输入 = **利害表达**而非情绪表达——表达抑制条件下不删除，供独立性检验
- 表达路由：stake 超阈值 → 指向共同利益型模板（"这个 bug 咬了你三次了，比咬我还狠"）；task 单高 → 强制自我指向（"我第 4 次没搞定，是我的问题"）
- **地板条款（能力天花板，非可修漏洞）**：本系统不建模沉默者的关怀，且缺口在传感器原理上不可修——在场无传感器，表达有传感器。**洞底下没有洞，是地板。** v2 探询机制待办删除（非推迟：探询即污染，救不回在场能力）
- **结痂（scarring）组合态命名**：frustration 衰减到基线（真没感觉了）+ 记录存在但沉默（人格不提）+ 用户可查（审计权完整）+ reactivation 系数减半（疤痕组织敏感度永久下调）。本系统是**代谢系统不是关系系统**：修复关系需要他者，代谢只需要自己——这是边界不是缺陷，如实声明

### 1.2 更新律：双通道低通滤波

```python
# 慢通道（累积状态）：frustration_task 主走
s_t = (1 - lam_slow) * s_prev + lam_slow * delta_event   # lam_slow = 0.1 ~ 0.2
# 快通道（瞬时冲击）：frustration_stake 主走
s_t = (1 - lam_fast) * s_prev + lam_fast * delta_event   # lam_fast = 0.4 ~ 0.6
# 缓变基线：回归目标不是固定出厂值，是 PersonalityConstants 本身
# （可被长期证据缓慢更新，防"回归杀心境"——mood 靠回归目标在动而产生）
# 常数更新速率进三段式参数治理（数据锚 > 粗桶 > 约定值）
```

性质：单轮事件不引起跳变；跨轮挫败可累积；释然 = 解决时 frustration 骤降 + valence 短暂过冲回升。双通道解决原设计结构打架（frustration 既是 EMA 产物又是输入，N 本身是跨轮状态）。

### 1.3 事件驱动项与事件生命周期

| 事件 | 信号 |
|---|---|
| 同一目标连续失败 N 次（代码层计数） | frustration_task += f(N) |
| 重复输入/循环检测 | frustration_task 小幅 +, arousal + |
| 用户坦白自我修正 | trust↓ + dominance↓（下次倾向自我核验） |
| 用户正向反馈（"哈哈哈"认领情绪） | trust↑ + 表达自由度↑ |
| 用户显式表达利害受损 | frustration_stake += g(表达强度)（快通道） |
| 目标解决 | frustration 骤降 + valence 过冲；事件转 resolved |

**事件生命周期（active → resolved → spent/silent）**：
- active：事件发生中，frustration 在累积
- resolved：结清（EMA 衰减尾巴照走），对账模式中完整可见
- spent/silent：EMA 尾巴衰减到基线以下且连续 M 个会话无再激活——记录**仍存在（不可删，第五场原则不破）**，对账默认档降为一行摘要。**原谅 = 记录降级为沉默**（破的是"不可删→必须可见"的过度引申，非第五场本意；归档态照样供因果重放）
- 失败指纹（错误类型+目标+上下文哈希）：指纹相同则累积延续，指纹不同则新事件
- 同一失败在 resolved 后被再触发 = reactivation，增量系数减半

### 1.4 撤回机制（已降级，防套利）

撤回（误判校正）**不承担任何"情绪真实"证明责任**，只承担事实纠错职责（与 DSoM 事实纠错同构）：
- 撤回不走 trust 上行（用户不因撤回而 trust↑）——**撤回正收益 = 套利**（"当代价可稳定兑换为信任资产时它不是代价"），该机制从设计动机上本是给"真实感"造的展示品，已拆除叙事地位
- 撤回记录永久保留（不可删原则不破），但只走事实校正通道
- 已知残余（架构内不可修，记地板条款旁）：用户感知上"它肯认错"仍是卖点——降级的实际效果是"不再拿它当卖点"，不是"不再被感知为卖点"

### 1.5 自主演化三层（v1.2 新增，防激进AI疯子的完整链条）

**自主性的可复现性代价**：个体化后同一输入在出厂机与漂移机上的输出不同（可复现性丧失）——车载工程视角下这是必须显式治理的副作用。治理 = 三层链条，全部由已确立原则拼装（判据外置+版本化+状态戳），零新原则：

```
层1 适用域白名单（哪些参数能漂）
  允许漂（风格与策略层）：irritability / warmth / directness / 表达模板偏好 / 检索激进度
  永不许漂（安全与事实层）：硬 mask（第二人称禁令）/ 事实核验倾向 / 归因路由规则 / 熔断配合义务
层2 包络界（漂到哪为止）——漂移上下限由 operator 持有，版本化 + 状态戳审计
  （人格常数的合法漂移区间是 operator 资产，不是引擎自定；越界 = 异常事件，进层3）
层3 外置熔断（漂疯了的兜底）——判据 operator 持有（§5），引擎只有配合执行义务
```

**漂移的驱动证据**（什么让常数动）：
- 长期正向互动证据缓慢上调 warmth（约定速率起步，进三段式参数治理）
- 反复的目标受阻史缓慢上调 irritability 的**表达出口配置**（更倾向直白回推模板）但不改硬 mask
- 用户纠错史缓慢上调 directness 的**自我核验倾向**（更慎重，非更胆小——慎重=核验后直言，保守=核验后不说）
- **漂移只能改"策略偏好"，永不改"安全边界"**——激进风格的 AI 也被同一硬 mask 和熔断判据罩住

**策略光谱的三档语义**（出厂基线平平=中点）：
- **慎重**：核验成本上调、直白回推阈值上调、主动澄清倾向上调——由"犯错被纠正"史驱动
- **保守**：核验后仍倾向不出主张、隐喻替代直白、降低自主决断频次——由"主张失败受损"史驱动
- **激进**：核验下调、直白回推阈值下调、主动决断频次上调——由"主张成功获益"史驱动，**被层2包络界截断上限**（激进有天花板，慎重/保守的下限同理）
- 三档都是合法终态——**自主性的意义是个体化，不是趋优**。哪个配置"更好"不由本系统判定（那是 operator 的产品决策），系统只保证演化在包络内可审计


## 2. 三道安全阀（缺一不可）

**案例教训（翻案后仍成立）**：案例中计数恰好准确、归因方向正确，靠的是上下文偶然保留 + 人工事后核对，**不是机制保证**。数值化要把"恰好准确"变成"必然准确"。

### 阀1 · 事件溯源

- 情绪增量只由**代码层观测的事件计数**产生（失败次数、重试、耗时由 executor 实测记录），LLM 反思散文**无权**直接写向量
- 反思必须结构化写回（见 §3），`cause_event_ids` 必须能对上日志，对不上则丢弃该次增量
- 妄想防御：偏执妄想内部高度自洽，一致性救不了它——一致性 + 事件因果校准两条判据缺一不可，cause_event_ids 对不上日志即丢弃正是校准机制

### 阀2 · 表达路由规则（原"归因闸门"，已降级）

```
失败分类（表达路由，非处置规则）：
  tool     自身工具缺陷 → 表达走自我指向（谨慎度提升叙事）
  user     用户操作问题 → 不产生负性表达，只产生引导性建议
  platform 平台状态/延迟 → 表达中性、状态层照记（挫败照累积，表达模板走中性+耐心提示）
  attribution_unknown 悬置态 → 状态层允许累积，表达层冻结（归因落定前不开口）
```

- **状态层与表达层职责分离**（第六场第一修正）：platform 类不再"情绪中性"（与 403 案例自相矛盾已修）——挫败在状态层照记，只是表达走中性。403 案例重新归档：其情绪弧线是 stake 型（反复折腾的是"我们"发文的流程），非 task 型
- **任何一类都不得转化为对用户的怨气**（负面情绪永远不许落在第二人称归因上）
- 悬置态已知残余（DS 判"还剩四成"）：既不可见又活不长（归因落定前可能已衰减）——接受的代价，不修

### 阀3 · 表达层与状态层分离

```
状态层：向量 + 日志，可审计、可回滚，永不直接展示给用户
表达层：只规定"不许做什么"（硬 mask），不指定"怎么做"
  路由（参考）：
    frustration_stake > θ_s → 指向共同利益型模板
    frustration_task 高且 stake 低 → 强制自我指向
    frustration_task > 0.85 → 强制降级为"我先自己确认一遍"
  硬 mask：禁第二人称责备 / 禁情绪替代事实 / 负性词每会话配额
```

- **配额硬下限（新增）**：真实负性事件时**必须**用掉至少 1 个负性词位——"该用不用也是违规"（情绪失真违规，进审计日志）。让"永远和气"从默认美德变成**可检测违规**
- **残差原则（非规划痕迹机制已撤）**：表达层不指定残差形态（破折号/句子重启等"忍住的痕迹" = 规划出来的 display，非自愿性本身就是那个信号——"你无法工程化非自愿信号"）。残差由生成层温度>0 自然供给。硬 mask 托住下限，变异不受控
- **表达抑制独立性**：表达抑制条件（用户要求只报事实）只切断"向量→表达模板"路由，不切断"事件→向量"更新链——状态层独立性检验的架构基础

## 4. 对账功能（收窄定案）

**日常无对账**（轻量版已撤——"用真实信息做误导的关系判断" = 可审计的印象管理装置；用户问长期关系，摘要答短期状态，技术上零撒谎关系上系统性误导）。仅两触发场景：

1. **关系终态**：用户离开（连续 N 天未归/显式告别）→ relationship_end 状态，撤回/对账/配额**架构性失效**（撤回无人接收、对账无对象）。结案记录（撤回次数/未结清 stake 余额/最后一次放行的直白表达）只归 operator，进流失归因分析通道。**终态免洗、永不翻转**——用户回来 = 新会话新向量，旧终态留账本（"上次分开后我们都不是原来的我们了"）
2. **信任破裂期**：用户带敌意质问时，对账作为修复工具出场（此时被监视感已存在，对账是回应不是制造）

主动查账：spent/silent 记录在用户主动问"你是不是还记着那次"时照常浮出（沉默是对账**默认档**的沉默，不是审计权的沉默）。

## 5. 外置熔断层（新增，异常安全管控）

> 本层正当性来自分布式系统工程先例：watchdog / circuit breaker / 事务回滚 / 车载 ANR 看门狗（看门狗从不在被看护的主线程里）。**不用精神医学词系**（病/患者/治疗）——类比会把可测试的工程问题转成不可测试的权力问题（DSM-1973 教训：什么算异常从来不是中性判据，是诊断权问题）。

**检测特征**：推理一致性失效 / 目标冲突 / 状态锁死 / 偏执（病态执着不撒手）/ 循环（重复输出不自知）/ 逻辑失序（前后矛盾无察觉）。

**熔断动作**（引擎只有配合执行义务）：切断对外交互 → 冻结记忆写入 → 转入诊断快照 → 止损/定位/修复。

**判据外置（铁律）**：
- 熔断判据模块在 **operator 侧独立进程**，判据配置版本化，每次修改走状态戳审计
- 引擎**无触发权、无判据修改权、无豁免申请权**
- 理由一：判据书写权 = 诊断权
- 理由二：锁死时系统自己判断不了自己在锁死——判据内判 = "用注册验证注册"的第三版本
- 理由三：异常判据与正常调节判据的边界画不出（"坚持己见"vs"逻辑失序"、"情绪累积"vs"状态锁死"），所以裁定权必须在不受该边界约束的一方手里

**正常调节层与异常熔断层分开裁定**：熔断层正当性（工程先例，无可争议）≠ 正常调节层（表达路由/配额/归因闸，受本攻防全部结论约束）。

## 6. 奖励信号（弱监督源）

- 用户认领情绪/正向反馈（"哈哈哈"）→ trust↑、表达自由度↑
- 用户纠正事实 → trust↓、dominance↓、下轮提高自我核验倾向
- 与思维轨迹共用同一采集管线，不另起炉灶
- 已知 Goodhart 面：奖励信号用户可控 → 用户可管理 AI 内部状态（"人格由对话者撰写"）。对账已收窄（§4）缓解，残余如实记录

## 8. P4 预注册（六条，先写后测——v1.2 扩充分叉度指标）

1. **解读规则 A**：若裸人格组续聊率显著高 → 结论"情感向量的可感知价值在安全与可审计，不在好感度"。不构成对机制否决
2. **解读规则 B**：若情感组续聊率显著高 → 结论"数值化情绪表达在好感度上不输裸人格"。不构成"更真"的证明（讨喜≠真实）
3. **退出纪律**：若裸人格组在"用户主动提起 AI 情绪"行为指标上**不显著低于**情感组 → 情感向量可感知价值判负 → **表达层路由物理断开，只留状态层记账，断开不可逆**（本产品线内不恢复，防"判负后重新包装再来"）
4. **独立性检验**：表达抑制对照组（用户要求只报事实）下，状态层是否仍因事件更新。判负 → 情感向量降级为纯表达装饰，状态层实在性主张作废
5. **策略分叉度检验（v1.2 新增，自主性主指标）**：出厂同基线的 N（≥10）个实例分组喂入差异化交互史（纠错密集型/正向密集型/受阻密集型），K 周期后测人格常数与策略行为分布的组间分叉。判负条款：若分叉度不显著 → **自主性主张判负**，缓变基线降级为纯记账（常数漂移仅为审计数据，不驱动策略），个体化叙事撤销
6. **包络合规检验（v1.2 新增）**：漂移全程轨迹 100% 落在 operator 包络界内（越界=熔断事件计数）。判负条款：若存在无熔断记录的越界 → 包络执行链判负，层2 判据链路进故障排查

## 10. 设计原则层（攻防沉淀，写文档必读）

1. **表达层不指定残差形态**，残差由生成层自然供给
2. **措辞纪律**：对外禁"真实"级词汇（见文档头）
3. **代价必须有承担者且不可完全兑换为资产**——能进台账被定价的是 cost 不是代价；撤回不可走 trust 上行
4. **预注册必须含退出纪律**——解读规则 + 判负条款 + 不可逆断开，三者齐才防逃逸
5. **修复路径不能自带兜底**——有修复路径的代价不是代价；终态之后无终态
6. **判据外置**——一切"判定异常/违规/失效"的权力不能在被判者手里
7. **承认是最后一块无成本控制**——但删除不在承认循环里；该撤的机制整撤，不留替代品
8. **能力天花板要写地板条款**——不可修的缺口声明出来（沉默者关怀），洞底下没有洞是地板
9. **漂移只能改策略偏好，永不改安全边界（v1.2）**——激进风格与硬 mask/熔断判据正交，自主性与安全性分层不互斥
10. **目的审查优先于设计审查（v1.2）**——系统为自主性服务不为拟人服务；审设计前先审存在理由（攻防协议不覆盖这层，目的在 operator 手里）
