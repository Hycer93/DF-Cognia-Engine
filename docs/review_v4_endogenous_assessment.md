# v4 内生驱动系统方案评估

> 评估对象：`docs/design_v4_endogenous.md`（2026-11-16 构思定稿）
> 评估时间：2026-11-23
> 前提修正：方案面向「本地个人 Agent + 自建本地模型（双 3090 + ollama）」，非云端 API。

---

## 一、总体判断

| 维度 | 评级 |
|---|---|
| 作为 vision 蓝图 | **A** — 方向正确、分层合理、有哲学立足点（内生≠追目标，而是掌握状态切换权） |
| 当前可直接开工部分 | **B+** — 阶段 1-2-3 有 v3 资产可复用 |
| 最终产物成熟度上限 | **中上（见 §四推算）** |
| 完全达成概率 | **中等偏低（见 §五推算）** |

**一句话**：方向对、分层对、落地顺序对；最大不确定性不在架构，而在「记忆质量」与「算力/工程投入」两个现实约束。

## 三、必须提前规避的三条坑

### 坑1：心跳层与推理层的节拍错配
本地 ollama 跑 8B/14B，单次推理几百 ms~数秒；双 3090 若同挂感知模型，显存紧张。
**对策**：心跳层设计为「非阻塞投递 + 异步回填」，绝不能同步等推理返回卡住主循环。

### 坑2：四大张量不要硬拆追求正交
方案 §八评审注提「两两余弦>0.7 需合并」。人格与价值观天然纠缠。
**对策**：单模型+拼 prompt 形态下，先只做「人格基线（稳）+ 动态注意力（动）」两张力；
价值观/目标先用文本规则承载。等真上多模型隐通信再拆细，否则造伪正交向量自找麻烦。

### 坑3：深度闲时产出必须进人闸+带证据+可打分
夜间脚本产出可验证（记忆多了几条/漂移归零）；闲时发散产出极难验证。
「跑了有概率产生价值」成立的前提是：产出不直接落库污染记忆。
**对策**：保持方案 §三 97 行原设计——高价值标「待同步」、修改只生成提案、经人闸终审。

## 四、最终产物能到到什么程度（推算）

**定位上限：一个「有持续人格与记忆、能自主张弛调度、可在本地离线常驻运行的单体个人 Agent」——类贾维斯的「初级形态」，不是科幻级 AGI。**

具体能到什么程度，分三层看：

### 能做到（概率 70-85%）
- 人格/语气/思维习惯跨会话稳定（靠 persona_anchor 拼 prompt）
- 记得住长期经历（事实与偏好），能主动关联旧事
- 无人时自主整理记忆、做阶段复盘、生成待办提案
- 本地离线、数据不外流、7×24 常驻
- 有明确的「工作态/闲时态」节奏感

### 勉强能做到（概率 30-50%）
- 真正「感知环境」（声音/视觉常醒）——工程量大、误报率难压
- 闲时「自主产生有价值的新认知」——大概率产出大量低价值噪声，需人筛
- 阶段目标自我对齐并可靠提案——容易过度自信或跑偏，人闸负担重

### 很难做到（概率 <15%）
- 多子模型隐通信「共享内存对齐张量」——这是研究级难题（坑2/原问题4）
- 真正的「自我演化人格」而不漂移——人格稳定与成长本身是矛盾
- 脱离人的持续投入而「自主进化」——方案自己也承认人闸终审是铁律

## 五、完全达成概率（推算）

**按当前架构设想整体实现：约 20-30%。**

拆解依据：

| 因子 | 权重 | 现状 | 影响 |
|---|---|---|---|
| 架构方向正确性 | 高 | ✅ 对 | 正 |
| 阶段1-3 可实现性 | 高 | ✅ 有资产 | 正 |
| 记忆质量能否支撑 | **极高** | ⚠️ 见下 | **最大拖累** |
| 硬件/算力投入 | 高 | ⏳ 待到位 | 中 |
| 阶段6 隐通信 | 高 | ❌ 研究级 | 拉低 |
| 人持续投入意愿 | 极高 | 取决于你 | 决定项 |

### 关键拖累：记忆质量现状（真实数据 2026-11-23）

| 指标 | 数值 | 判断 |
|---|---|---|
| 记忆卡总数 | 324（runtime 184） | 规模尚小 |
| 关系边 | 280 | 稀疏 |
| **冲突积压** | **149 条** | ⚠️ 接近总量一半待处理 |
| 隔离区 | 43 | 偏多 |
| **置信度 L0+L1** | **283/324 ≈ 87%** | ⚠️ 绝大多数低置信 |
| **可复现 repro=derived** | **60/324 ≈ 18.5%** | ⚠️ 仅少数完全可复现 |

**结论**：v4 的人格/闲时整合全部建立在「记忆可信」之上。而现在记忆**近一半有冲突待处理、87% 是低置信、只有 18.5% 完全可复现**。
→ 「记忆系统成熟前不开人格」的判断**完全正确**。记忆治理（降冲突、提置信、增可复现）是 v4 的**前置硬门槛**，不是可选项。

## 六、最重要的一块内容

**如果只能抓一件，抓这个：记忆质量工程（冲突治理 + 置信度校准 + 可复现性）。**

理由：
1. v4 全部上层（人格、闲时、自我对齐）都吃记忆的饭——记忆不可信，上层全是空中楼阁。
2. 当前数据明确显示这是最大短板（149 冲突 / 87% 低置信 / 18.5% 可复现）。
3. 这是**你能完全控制、且每投入一分立即见效**的部分，不依赖硬件、不依赖研究突破。
4. 而方案里最炫的部分（显存张量、隐通信、闲时发散）恰恰依赖最难满足的条件。

**优先级建议**：
```
记忆质量工程（现在，最高优先）
  → 阶段1-2 常驻化（硬件到位前即可做）
    → 阶段3 闲时整合（带人闸）
      → 阶段4 多模态（等 3090）
        → 阶段5-6（远期，视前序效果决定是否投入）
```

---

## 七、给未来的执行原则

1. **不要先建宏大架构**，先让现有记忆系统「可信」，再谈人格与自主。
2. **每一阶段用可验证指标决定是否继续**（如：冲突积压降到 <10%、L2+ 占比 >50%，才开人格）。
3. **保留 v4 作为北极星**，但路线图以「记忆质量 → 常驻化 → 闲时」为实序。
4. 阶段 6（隐通信）在单模型路线下**不投入**，等真有多模型共享内存能力再议。
