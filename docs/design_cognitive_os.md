# 周期式记忆门控分布式认知内核方案（架构宪法 v2）

> 状态：设计构思稿，评审通过（2026-11-04）。
> 定位：**两腿架构之腿2（时间连贯性放大器）**——实施排序在腿1（思维蒸馏进权重，P0 数据管线）验证之后。腿1 决定价值上限，本方案放大其价值（单轮智力 × 时间连贯性 = 乘法）。
> 原文关键修正：O 集群已从"分布式算子"改为"蒸馏后的权重内化思维"（作者自决，2026-11-04）。

## 一、方案概述（原文定稿）

基于元始认知引擎七层认知流水线、21 项原子骨架（G01-G21）原有规范，升级运行范式：

- **摒弃**事件触发式调度 → **改为**周期后台常驻 + 事件唤醒加速的混合调度
- 记忆能力独立为**专用门控内核（M 核）**，骨架拆为无状态算子 → **修正为权重内化**
- 依托记忆内核的门控、快照、版本隔离，实现：后台持续认知沉淀、意图驱动按需分发、并行协同推演
- 弱化对超长上下文、无差别原始文本缓存的依赖——**上下文是耗材不是容器**（与 v3 同一信条）

核心信条：以结构化元结构作为认知流载体，区分**长期记忆存储**与**前台工作认知集合**。

## 二、修正后的架构

```
M 核（记忆 & 全局门控，唯一有状态内核）
  ├ 常态周期任务（无外部输入版——离线再加工已有状态）：
  │    情感基线回归（EMA 向出厂基线缓慢回归）
  │    高频边合并 / 置信度衰减 / 周期出清（G16 机制化）
  │    轨迹蒸馏预处理（闸门筛选、去重、按结构类型分组）
  │    等价结构提纯 / 隐性共识挖掘（LLM 式，攒量后启用）
  ├ 意图门控：不粗暴中断记忆事务，COW 生成只读快照 + TraceID，
  │    任务包 =【用户意图 + 元结构快照 + 任务约束】，分发后恢复后台
  └ 进化护栏：后台只可改元结构参数/关联；骨架规则变更需审批（防自毁收敛）

O（原分布式算子集群 → 修正为蒸馏内化权重）
  骨架不再是外置算子，是模型张口即有的推理结构
  完全内化存疑项：何时深/浅的判断可能始终需要外置路由

Bus（简化甚至消失）
  单模型内无跨算子消息传递需求；快照隔离思想保留
```

### 运行时序

1. 常态空闲：M 核周期整理；情感向量缓慢回归基线
2. 意图抵达：M 核生成稳定快照，封装任务包
3. 推演：内化权重的模型基于快照子集推理（前台激活集合受控，不塞全量历史）
4. 收敛校验：意图回归 + 对冲校验（G11 怀疑在代码场景有客观锚点，收敛条件天然）
5. 回流：有效新增元结构打包回流 M 核校验合并；系统回归常态

## 三、空闲任务清单（原料自足，修正"空转"误判）

| 任务 | 原料 | 机制 | 实施状态 |
|---|---|---|---|
| 情感基线回归 | 向量历史 | 规则式 | P2（随 affect vector） |
| 高频边合并/出清 | edge_log | 规则式 | **可先行** |
| 轨迹蒸馏预处理 | 走链轨迹 | 规则式 | 管线已有，缺批量 |
| 等价结构提纯 | 记忆存量 | LLM 式 | 攒量后 |
| 隐性共识挖掘 | 跨题轨迹 | LLM 式 | 远期 |

人脑类比：睡眠整理的是海马体当天缓存，非实时输入——离线再加工。白天采集密度决定夜间整理密度（P0 管线同时是前台数据源和后台整理粮仓）。

## 四、对 AI 的帮助评估（评审结论）

## 五、两条腿风险矩阵（本方案的生死条件）

| 腿1 蒸馏 | 腿2 本方案 | 结局 |
|---|---|---|
| ✅ | ✅ | 完全体：单轮智力 × 时间连贯 |
| ✅ | ❌ | 聪明但失忆（业界现状+思维内化，仍有价值） |
| ❌ | ✅ | **最危险**：外置骨架+强记忆 = v3 加强版，A/B 已证增益撑不起成本 |
| ❌ | ❌ | 归零 |

结论：腿2 不能独立产生价值，只能放大腿1。**P0 总闸门地位再次确认。**

## 六、§6 边界说明（原文最有价值的一段，保留）

本架构为认知编排操作系统，可在中等上下文能力的基础语义模型之上运行，实现工程层面的连续自主思考，**但架构本身不自动生成内生主观主体**；系统的目标、价值锚点仍需额外独立的身份与目标堆栈模块注入。

评审注：此边界声明与"自我=持续性+主视角+反身性"框架对齐——本方案提供持续性与反身性，主视角显式划出界外，由情感向量（利害结算）路线承接。这是理论诚实性的体现。
