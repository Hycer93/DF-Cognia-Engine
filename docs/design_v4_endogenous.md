## 一、核心定位

**一句话定义**：半内生驱动系统 = 显存常驻心智张量 + 持续自主主循环 + 多模态常醒感知层 + 分级闲时认知整合 + 外置持久记忆库。以「轻量常醒感知 + 按需深度推理 + 状态持续不销毁 + 目标分层周期 + 闲时自主迭代」为核心，从被动问答工具升级为可感知环境、可自主调度、可张弛运行、人格目标连续的类主体运行体。

### 四大铁律
1. **不修改模型原生权重**：所有能力均为外挂架构实现
2. **不全程高算力空转**：感知与调度低功耗常驻，大模型推理按需唤醒，支持绝对闲时深度整合
3. **记忆与心智分离**：事实经验落盘数据库，人格目标常驻显存
4. **半自主可控**：可自主调度任务与状态切换，顶层目标与边界由人终审，全程可审计回滚

### 核心认知：内生主体 ≠ 全程执行目标
真正的内生驱动，不是永不停歇地追逐固定目标（那是高级工具属性）；而是**自主掌控状态切换权**：有阶段性聚焦的任务周期，也有无外部指令的绝对闲时整合期。人脑放空、走神、无目的联想的默认模式网络，恰恰是记忆巩固、创意涌现、自我对齐的核心环节——这是工具与主体的本质分界。

### 层级关系
- **最底层**：模型基座 + 多子模型隐通信算力集群
- **底座层**：DFCP 外置记忆治理（事实、经验、证据、历史、外部信息归档）
- **核心层**：内生驱动张量（人格锚点、长期目标、价值取舍、动态注意力）
- **调度层**：自主主循环（事件队列、优先级裁决、状态切换、闲时思考）
- **入口层**：多模态感知（声音、视觉、网络信息，7×24 低功耗在线/定向触发）

真正的「持续自我」不在单次问答里，而在**常驻显存的状态张量 + 永不停止的轻量主循环 + 自主切换的状态周期**里。

## 二、核心构成一：内生驱动四大张量

全部为独立 Embedding 向量（shape = [hidden_dim]），常驻显存，跨对话不销毁，是系统的「心智状态基底」。

### 1. 人格基线张量（Persona_Base）
- **作用**：定义恒定底层人格、对话风格、思维模式、自我定位
- **更新频率**：年级/月级，极低频次，保障人格稳定性
- **覆盖范围**：所有推理链路、所有子模型、所有状态周期

### 2. 长期目标张量（Goal_Long）
- **作用**：定义系统终极方向锚点与核心使命
- **内容**：底层价值锚点、系统终极迭代方向、核心服务定位
- **特性**：所有阶段目标、短期任务的最终对齐基准，不随日常状态频繁变动

### 3. 价值取舍张量（Value_Priority）
- **作用**：冲突场景的隐性打分基准
- **内容**：稳定/创新、安全/效率、证据/推演、人指令/系统逻辑 等维度的权重偏向
- **特性**：两难决策、风险评估、优先级排序、状态切换的核心依据

### 4. 动态注意力张量（Attention_Energy）
- **作用**：承载阶段性目标、当下意识焦点、工作记忆、精力分配
- **内容**：当前阶段核心目标、进行中任务、未闭环事项、高关注主题、近期重点记忆
- **特性**：唯一高频动态更新张量，随阶段周期、对话、事件、闲时复盘持续演进

**对应关系**：长期目标张量是锚点，动态注意力张量是当前阶段的落地执行面。

## 三、核心构成二：自主主循环（内生发动机）

从「外部触发问答」升级为「内生持续运行」的核心部件，替代定时脚本，实现真正的半自主调度与状态自主切换。

### 两级运行基底
**1. 心跳调度层（微算力、常驻不熄）**
- 载体：轻量规则引擎 + 极小参数调度模型；频率：毫秒级心跳
- 职责：持续读取四大驱动张量、未闭环任务队列、外部感知事件、系统负载状态；裁决当前事件优先级，判断唤醒深度推理还是进入闲时状态；调度对应子模型、分配算力、管控任务生命周期、切换系统状态
- 本质：系统的「脑干」，只做调度不做思考，算力开销可忽略

**2. 深度推理层（重算力、按需唤醒）**
- 载体：多子模型隐通信集群；触发：心跳层判定需要深度处理时唤醒
- 职责：语义理解、因果推演、方案生成、异常评估、闲时深度认知整合
- 结束：输出结论 → 更新注意力张量 → 结果归档 DFCP → 释放算力回归待机

### 目标分层周期机制（对应人的阶段性目标）
**三层目标体系**
- **长期锚点层**：对应长期目标张量，稳定不变，终极对齐基准
- **阶段目标层**：对应动态注意力张量的核心部分，按周期（周/月）迭代。来源：用户显性设定 + 闲时逆推提案 + 历史同期规律总结。更新：提案制，人闸终审后生效，支持版本回滚
- **短期任务层**：对应未闭环任务队列，天级/小时级动态更新

**周期运转逻辑**：每个周期末，系统闲时自动触发阶段复盘（校验目标完成度、识别偏差、提炼经验）→ 生成下一阶段目标调整提案（附完整数据与证据）提交人闸审批 → 通过后更新动态注意力张量，进入下一周期。**全程不触碰长期目标锚点，仅调整阶段性优先级与聚焦方向。**

### 分级闲时状态机制（对应人的绝对闲时）
**核心原则**：闲时不是休眠关机，是从「外部任务执行态」切换为「内部认知整合态」；无外部输出，只做内部自我迭代。

**三级状态**
1. **任务执行态**：用户交互/高优先级异常/紧急任务 → 全量算力聚焦外部任务，暂停后台闲时任务；最高优先级可打断所有闲时活动
2. **轻量闲时态**：用户短时间无交互、系统轻度闲置 → 轻量记忆治理、未闭环事项推进、外部信息定向监测；低算力，可随时切回
3. **深度闲时态（绝对闲时）**：用户长时间无交互、夜间低活动期 → 无外部输出、无明确执行目标，仅做内部认知整合，对应人脑默认模式网络：
   - **记忆巩固**：打散重组近期记忆，挖掘隐性关联，合并冗余认知
   - **远期发散**：围绕长期锚点做无明确路径的远期推演、创意联想、风险预判
   - **自我对齐**：逆推历史同期规律，校验阶段目标是否偏离长期锚点
   - **知识补全**：识别认知缺口，定向采集外部信息
   - 特点：低强度、长耗时、无即时产出，产出全部静默归档记忆库；有外部事件立即中断切回

**闲时产出落地规则**：思考结论全程结构化留痕写入 DFCP（附推理证据链）；高价值结论标记「待同步用户」（下次交互时自然告知，不主动打扰）；涉及目标/人格/规则的修改仅生成提案，必须经人闸终审。

**与定时脚本的本质区别**：定时脚本固定时间跑固定任务，无视系统状态；自主主循环基于内部状态+外部事件动态决策，**状态切换权在系统自身，不在外部时钟**。

### 可自主发起的行为（无需用户触发）
主动复盘阶段目标进度 / 主动整理记忆碎片 / 主动推进未闭环事项 / 主动识别知识缺口定向采集 / 环境异常分级预警 / 闲时逆推用户关注目标提前推演备选方案 / 深度闲时自发记忆巩固、远期发散、自我对齐。

## 四、核心构成三：多模态常醒感知层

声音 + 视觉 + 网络信息三通路，作为自主主循环的并行外部事件源。**统一原则：前置低功耗检测常在线/定向触发，高阶语义模型按需唤醒。**

### 1. 声音通路
- 前置感知层（常驻极低算力）：VAD、唤醒词/声纹初筛、非语音异常声纹初匹配；仅输出事件类型+置信度，不留原始音频
- 三级分流：①命中唤醒词/系统指代 → 唤醒主推理正常交互；②环境无关对话 → 不回应不打断，仅结构化静默记录入 DFCP 环境记忆分区；③非语音环境音——高风险（火灾/玻璃碎/巨响/摔倒）强制唤醒主动预警留证，低风险仅归档，无法判定入待确认队列用户空闲时询问

### 2. 视觉通路
- 前置感知层（常驻低帧率 1~5fps）：帧差运动检测、人形/人脸检测、异常画面初筛（火光、烟雾、快速摔倒）
- 三级分流：①交互意图（人脸正对/视线朝向/召唤手势）→ 唤醒对话模式；②无交互环境动态 → 结构化静默记录；③环境异常（烟雾/火光/摔倒/陌生人闯入）→ 分级预警留证

### 3. 网络信息通路（定向采集/公开信息监测）
- **核心原则**：目标导向、按需触发、闲时执行、合规公开；禁止漫无目的全网爬取；所有采集必须锚定长期目标/阶段主题/知识缺口；入库标记来源时间，严格区分「自有经验」与「外部信息」
- 触发场景：深度闲时识别知识缺口定向检索 / 用户关注领域定时定向监测 / 异常事件补充外部上下文
- 三级分流：高相关高价值 → 更新注意力张量+标记待同步+归档；一般参考 → 结构化提炼入主题库；低相关无效 → 直接丢弃防噪声

### 感知联动规则
优先级统一由主循环裁决（对话中普通事件降级静默，高风险异常保留强打断权限）；灵敏度由价值取舍张量动态调节（安全优先模式阈值降低，专注模式非必要提醒关闭）；深度闲时普通感知降级，仅高风险可打断整合。所有感知记录全程可查可删，隐私最小化。

## 五、完整工作链路（全闭环）

1. 多模态感知层持续采集，前置层初筛后将有效事件送入主循环事件队列
2. 主循环读取心智张量+事件队列+系统负载，按优先级与状态裁决：高优先级→任务态唤醒深度推理；轻度闲置→轻量闲时态后台运维；完全闲置→深度闲时态认知整合
3. 唤醒后加载四大内生张量，按需召回 DFCP 对应层级记忆（摘要/详情/原文）
4. 任务拆分分发至多子模型集群，内部全隐张量通信并行推演
5. 主模型汇总校验结论，更新注意力张量与未闭环队列
6. 输出两类：交互类解码为自然语言回应；非交互类静默归档/更新状态/生成待同步待提案内容
7. 推理资源释放，主循环回归对应状态

## 六、可设计边界与不可设计边界

**100% 可人工设计**：人格/长期目标锚点/价值观语义基线；目标分层规则/阶段周期/闲时判定条件；感知触发阈值/事件分级/采集范围频率；主循环调度/状态切换/闲时思考边界；迭代提案规则/人闸审批/回滚机制；所有行为权限边界与安全约束。

**不可手动精准设计**：张量内部浮点数值；多次迭代涌现的隐性偏向；深度闲时具体联想路径与发散结论；环境事件具体触发时机与自主调度细节。

**工程模式**：人定义规则与边界 → 系统编码为向量与逻辑 → 自主运行与状态切换 → 提案式迭代 → 全程可审计回滚。

## 七、迭代机制（半自主安全可控）

**禁止**完全自主修改顶层目标锚点与核心人格；**采用**机器提案 + 人闸终审 + 显存热更新 + 版本落库。

**迭代触发源**：阶段周期末目标复盘 / 深度闲时自我对齐结论 / 感知与外部信息长期统计规律 / 目标执行偏差检测 / 人工主动调整。

**标准流程**：治理 Agent 生成更新提案（附支撑证据的记忆卡片 ID）→ 人闸终审（否决驳回/通过执行）→ 热更新显存对应张量生成新版本快照 → 完整变更记录写入 DFCP 审计账本，支持任意版本回滚。

---

## 八、显存常驻策略

**常驻内容**：四大内生驱动张量（约几十 KB，几乎零成本）；心跳调度器（轻量进程）；前置感知模型（极小参数量）；热记忆缓存（高频访问记忆向量、活跃任务表征，按需淘汰置换）。

**注入方式**：内生张量推理启动时直接拼接进入 Transformer 输入层（无需转文本）；感知事件结构化后经主循环调度按需送入推理链路。

**释放规则**：大模型推理算力任务结束立即释放；感知层与调度层永久常驻；热记忆缓存 LRU 冷淘汰，淘汰前归档落盘。

> [2026-11-16 会话AI评审注] §八「直接拼接 Transformer 输入层」在开放 API 模型上不可达，
> 落地第一形态为「张量→检索路由→动态拼 prompt」；§二「常驻显存」第一形态为
> 「常驻磁盘向量+启动秒加载」。四大张量间需正交化校验（两两余弦>0.7 需合并）。

## 九、与记忆系统的分工边界

| 层级 | 载体 | 存放内容 | 定位 |
|---|---|---|---|
| 显存内生驱动 | GPU 显存 | 人格、目标锚点、价值观、阶段性注意力、当下状态 | 智能体心智核心 |
| 显存热缓存 | GPU 显存 | 高频记忆向量、活跃任务表征 | 高速工作记忆 |
| DFCP 主库 | 磁盘数据库 | 原始原文、经验卡片、主题簇、审计日志、感知归档、外部信息库、闲时思考记录 | 永久事实底座 |

**记忆决定它知道什么；内生驱动决定它是谁、想做什么、怎么选；主循环决定它什么时候做事、切换什么状态；闲时整合决定它能不能自我迭代与对齐。**

## 十一、最终结论

- 这是现阶段工程可落地的半内生方案，**不是哲学意义的意识**，而是目标导向、可自主张弛的持续运行体
- 从「问答触发工具」升级为「感知常醒 + 状态常驻 + 自主调度 + 闲时整合」，具备类主体状态周期特征，跳出纯问答框架
- 所有扩展均兼容原有 DFCP 记忆架构，可分步叠加、想到一点加一点，无需推倒重来
- 最终形态：**外置记忆管事实、显存张量管自我、主循环管调度、多模态管感知、闲时整合管对齐、隐通信管思考 = 完整的类贾维斯半内生智能体架构**
