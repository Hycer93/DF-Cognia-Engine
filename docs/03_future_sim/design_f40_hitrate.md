# F40 跨簇命中率考核规约 v1.0

> 定稿：2026-11-20（用户裁决）。F 系晋升 core 四门槛之门槛①的量化定义，
> README.md:118 "阈值待定后固化" 就此关闭。配套实现：`scripts/f40_cross_cluster_eval.py`。

## 核心规则

分母必须是**独立命题、拓扑不重复**的跨簇题，禁止反复复用同一套链路刷通过率。

**跨簇考题定义**：起点 topic ≠ 终点 topic，且路径 BFS 需跨过 ≥2 个主题簇；
隔离红线命中样本**不计入分母**。

**通过阈值**：跨簇 PASS 率 **≥ 80%**，每轮至少 **3 道**独立跨簇题计入分母。

## 1. 考题来源（三类混合，防单一来源）

| 类 | 说明 | qid kind |
|---|---|---|
| 主来源·自然链路 | judge 卡库 topic_links 图谱随机抽「源簇→目标簇」对，路径长度 ≥3、中间经过至少一个异簇节点；题干=原始卡真实对应工程问题，禁人工编造推理任务 | `natural` |
| 补充·边界拓扑难例 | 专造两类极限题：a) **稀疏边跨簇**——簇间仅单条弱边连通（易断链）；b) **多分叉**——一起点可走向多个不同簇（易走错分支） | `sparse_edge` / `multifork` |
| 长期供给·增量自动生成 | 每批带 topic 挂载的新 judge 卡入库后，扫描新出现的簇对自动追加进题库 | `auto_supply` |

## 2. 去重判定（防刷题）

两道题视为**同一考题**（不能重复计入本轮分母），满足任意一条即判同：

- 起点簇、终点簇完全相同，且主干途经簇集合重合；
- 底层用到的 judge 卡集合重合度 ≥ 80%。

> 判同看**图谱拓扑骨架**，不看文字描述——主干一样，换一句题干也算同一题。

## 3. 每轮校验配额

- 每轮 F40 校验：下限 3 道、上限 6 道独立跨簇题（防耗时爆炸）；
- 同一轮内：任意两题的簇对 (src_topic, dst_topic) 不得重复；
- 轮与轮之间：可复用旧题，但**不得连续两轮全部复用**——连续两轮必须至少新增 ≥1 道全新拓扑考题。

## 4. 统计口径

- 隔离红线触发 FAIL：**剔除**，不计分子分母（保护项非能力项）；
- 图谱缺边导致自然 FAIL：**计入分母**（真实能力缺陷，正是边覆盖率要还的债）；
- 单题 PASS 判据沿用最小闭环三指标：正向可达 ∧ 路径相交 ∧ 步数偏差（`future_sim_minloop.verify` 口径）；
- 达标判定 = `PASS/(有效分母) ≥ 0.8` ∧ `有效分母 ≥ 3`。

## 6. 口径锁死与扩池纪律（2026-11-20 用户终审确认）

- **F40 校验口径锁死**：每轮 3~6 道拓扑独立题、PASS率 ≥80%；红线隔离 FAIL 剔除出统计，图谱缺边 FAIL 计入分母。此口径不再复议，修订需显式重新裁决。
- **扩池硬约束**：后续任何来源扩充题库时，必须持续通过 `qualifies()` 的「真跨簇」条件——路径中间节点须存在异于两端的簇挂载，防止 patent 巨岛（94 卡）内部漫游链路混入假跨簇题。
- **方向规范化**：台账 `src_dst` 一律存排序后簇对（A→B 与 B→A 同键判重），入库脚本已强制；历史条目已于 r01 后批量规范化（3 条改写）。
- **标签纪律**（ecc0f6ae 踩坑归档）：新增裁决卡先核对 schema 白名单（domain=域-子域[-场景]编码、behavior∈BEHAVIOR_TREE、relation∈RELATION_TREE 七类、repro 交 judge_repro），禁止凭记忆脑补标签组合。
