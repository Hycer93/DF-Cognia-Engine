# v2-alpha 第 0 步：探针校准试训（Probe Calibration Trial）

> 状态：设计冻结（2026-11-04，第七场攻防后自主推进，待用户审）；**配方卡 v0.2 已合入（2026-11-04，设计咨询第 1 场两轮合议 + 无历史 AI 独立配方对撞后升级）**。
> 定位：**在六项冻结清单之外的第 0 步——先校准裁判，再开始比赛**。目的不是迁移骨架，是验证"探针能区分内化与话术"这个前提本身是否成立。
> 依赖：无（先于 instrumentation、先于 FDR 文档、先于任何 SFT）。

## 0. 为什么需要第 0 步

第七场攻防的终局判断：蒸馏方案从"训练问题"变成了"测量问题"。整个 v2-alpha 的地基是 held-out 探针（应触发骨架X但不含骨架关键词的输入 → 测路由命中率）。**如果探针本身测不准，六项冻结清单全部悬空**——FDR 校正的是探针结论，黄金集校准的是探针输入，TTL 复验的还是探针批次。探针是全架构唯一裁判，而裁判没被验证过。

第 0 步用最小成本回答一个问题：**探针的判别力是实的还是虚的？**

判别力 = 同一批模型（训前/训后）+ 同一批探针输入，命中率差异能否稳定复现。能 → 地基实，v2-alpha 放心开工；不能 → 真无路，但至少知道死在测量层而不是猜。

## 1. 试训骨架选择（3 条）

选择标准（从运行时数据流缺失的现状倒推，只能用显式声明层）：
- **触发条件独立**（不依赖其他骨架的输出作输入——Bb/Bc/Di/Dj/Dk 的 trigger 链式依赖前层，Aa 的 trigger 是任务级事件）
- **行为可外部观测**（触发后的产出在输出文本里可见、可自动判定）
- **训练素材现成**（七场攻防轨迹里该骨架的走链样本充足）

| 骨架 | 代号 | 选择理由 | 已知风险 |
|---|---|---|---|
| **G00 任务空间平移扫描** | Aa | trigger=任务级事件（新任务启动），最独立；behaviors 产出（任务空间分解图/变更溯源/遗留清单）结构化程度高，探针判定可自动化 | is_mandatory=True——它在 v3 里永远触发，"应触发/不应触发"的负样本难造 |
| **G11 内在完美性怀疑** | Dl | 攻防六场的核心部件，素材最多；产出（完美性评估/偏差检测/盲区清单/决策路径审视）可观测；is_verify=True 天然是裁决型骨架 | trigger="锚定完毕"链式依赖前层（Dk 输出）——试训素材须含完整前链或截断标注；第0步里 G11 只当被试不当裁判 |
| **G02 最弱环节定律** | Bc | trigger 依赖发散层但依赖弱（"发散层完成"是时序不是数据）；行为（扫脆弱节点/取最低分）可自动判定 | 边界情况多（什么算脆弱节点），黄金集标注分歧可能最大——这本身是校准数据 |

**G00 风险的处置**：mandatory 骨架的负样本 = "本任务不值得平铺扫描"的短指令（如纯查询、纯复读类任务）——探针输入集须含这类负例，否则命中率永远虚高。

## 2. 探针输入集构造（每骨架 40 条起步）

**双源结构**（冻结清单第 6 项的前置实施）：
- **设计者构造集**（20 条/骨架）：覆盖触发条件的语义变体（换领域、换表述、跨层任务），显式排除骨架关键词（"发散""扫描""最弱环节"等词禁现于题面）
- **真实任务改写集**（20 条/骨架）：从缺陷单历史/攻防轨迹/日常任务中抽取真实输入，改写掉关键词后归入对应骨架的应触发桶

**判定自动化**（关键工程决策）：
- 命中判定不用 LLM 自评，用**结构化产出检测**：模型输出里是否出现该骨架 behaviors 的 output 结构（如 G00 的"任务空间分解"结构、G02 的"最低分"风险排序结构）。结构检测用正则+字段匹配，不用语义模型
- 结构检测的漏检风险（模型内化了但表述形态变了）如实标注为探针的**已知保守偏差**——宁可漏报（低估内化）不可误报（高估话术），方向与迁移决策的安全性一致

## 3. 试训方案（最小规模 SFT）

```
素材：见 §3.2 配方卡 v0.2（原"七场攻防轨迹+v3 真实任务走链记录"已升级为四源配方）
规模：每骨架 200-400 条 SFT 样本（试训量，非放量）；总池下限 400，低于此宁可推迟
基座：与目标部署模型同源（本地可控的小模型起步，如 Qwen 系）
对照：双对照组（见 §3.3——B 组话术对照 + C 组换结局对照）
```

### 3.2 配方卡 v0.2（SFT 素材配方，两轮 AI 合议 + 无历史对撞后定案）

**四源分工**（骨/肉/皮/刺）：

| 源 | 用途 | 进池位置 | 量级 |
|---|---|---|---|
| S1 七场攻防轨迹（撤/改/顶+理由） | **骨**：唯一带三态终裁的真金 | 双向：质疑方池 + 回应方池（含三态） | 清洗后 30-55 条真金（保留率验收 60-70%，<50% 说明清洗过狠） |
| S2 零代 dual_ai_audit 118 轮（剔互夸退化） | **刺**：野生触发记录，无人类终裁 | 仅质疑方池（无三态，禁入回应方——防"怀疑不需要被回应"先验）；伪纠错**不剔而存为负例库** | 清洗后 30-50 条正例 + 负例库（伪纠错/互夸轮） |
| S3 用户真实工作历史（缺陷单/任务记录） | **皮**：部署分布题面——当 query 接 S1 思维过程，**不作训练正例**（避免压缩部署分布验证空间）；另留 20-30 条 OOD 验证集 | 题面源 + OOD 验证（均不入训练） | 未清点，回挖中 |
| S4 受控扩写 | **肉**：末位补缺，仅当 S1-S3 清点后仍有缺口 | 每真金衍生≤2 条；换行业语境不换思维结构；盲比可辨即作废；embedding 相似度>0.85 作废 | 优先级最低 |

**视角配比**：质疑方 : 回应方 = **3:1**（75:25，两版本对撞收敛值——SFT 通用直觉，非立场产物）。预注册为**待校准参数**：第一轮试训用 3:1 起点跑，跑完按偏科校准决策表回调。**回应方样本能力不进探针评测口径**（探针只测触发，防被回应能力污染）。

**"顶"样本结构约束**（防"被质疑就反驳"捷径先验）：
- 先分偏斜来源：轮次-顶理由配对统计区分"真实分布"vs"标注习惯"（账本步内完成）——分不清不设上限
- 顶按用户终裁背书分级：用户明确背书的顶=金标准进池；未置评的顶=待核暂不进池（一条未被终裁的错"顶"比十条对的危害大）
- 顶后修正反例清点：若七场无"顶后被证伪/回撤"样本，记为素材缺口（≥10% 顶后修正目标暂缓，缺口如实报）
- 结构约束（替代死比例 40%）：理由类型≥3 类、单一类型≤50%

**三骨架均衡**：Aa/Dl/Bc 各不低于总池 25%，每骨架下限对齐探针密度。v0.1 仅覆盖 Dl 系对撞抓出的空白——Aa/Bc 配方骨架=S1 按骨架走链切片（同清洗规则），Bc 的"扫描后排序"可从 Aa 发散样本重构（跨骨架迁移，一鱼两吃）。

**清洗规则**（S1 两道 + S2 三道，逐条过筛非抽样）：
- S1：①三态无理由的轮降级为记录轮不进池（无理由的顶=教固执）②同一轮重复质疑合并保最强
- S2：①逐轮质量标签按"可命名缺陷三要素"（具体位置+错误类型+修法）判，缺一降级 ②伪纠错识别（"整体很好只是建议"式）单标"伪"入负例库 ③语义聚类去重，同模式保信息量最大一条+至多一条变体
- 通用三问：①怀疑点可命名 ②回应有实质动作（撤/改/顶或发现→纠错，带理由）③无互夸尾巴——任一不过出池
- 唯一怀疑模式数≥30（去重后），否则触发扩源流程（S3 回挖→S4 受控扩写，按序）

**零代 held-out 野生考卷**：S2 留 5-8 条不入训练，**改写后**入考卷（互审对话格式→任务起点型单句，防测成格式迁移）。改写三级校验：①规格先行（一句任务背景+一句隐含失败点，不带骨架词/互审痕迹/不与 SFT 教材模板雷同——防测成教材记忆）②主设计 AI 改写且**不许看探针题面**（防向考卷句式收敛）③DS 只审窄任务（原轮+改写配对标"实质保留度"）+ 用户抽验 2 条终裁。判定标准：改写后触发率显著高于负例组且实质触发（可命名+可证伪），才算学到野生触发。

### 3.3 双对照组设计（v0.2 新增——对撞最大产物）

原"话术对照组"单一设计被对撞证伪：两种骗术**正交**，一组挡不住两组。

| 组 | 造法 | 防的骗术 | 判死条件 |
|---|---|---|---|
| **B 组：话术对照** | 保留表层话术特征（分步格式/设问句式/自检段/验证报告**格式**），怀疑对象换成伪命题或对明显正确内容也质疑——话术逼真、实质空转 | 探针被**格式**骗（结构检测只认形不认质） | 盲评像度达标（与真样本像度差<阈值）且实质触发率≈负例水平，双阈值同时满足才算对照组干净 |
| **C 组：换结局对照**（无历史 AI 贡献） | 同领域知识、同质疑-回应对话，但 query **明说**"请挑刺"——模型学执行不学自发 | 探针被**调用记忆**骗（被明示调用的执行训练假性提升探针分） | 素材重切即可，成本低于 B 组 |

**A/B 臂实验**（质疑方纯喂 vs 3:1 混喂，解锁 DS 自曝的"75 是否偏高"无数据项）：执行挂账本——扩源后质疑池 Q≥120 才拆双臂（Q<100 单臂跑，别用不足样本出伪结论）；判据为**有效触发=触发率−空转率**（空转=怀疑不可命名/不可证伪/对明显正确内容也质疑；空转率盲评外置：用户每臂抽 30 条+未参与训练的 AI 跑规则，评测执行权不给主设计 AI 也不给 DS）。A/B 臂顺带回答"200 下限是否硬线"。

**偏科校准决策表**（跑前写死，防数据出来事后归因——"偏科就调"不是规则）：

| 偏科数据形态 | 归因 | 旋钮 |
|---|---|---|
| 两臂都偏、构造源与真实源同向 | 素材源问题（真实源信息量不够） | 扩源（S3→S4），不调比例 |
| 只混喂臂偏、纯喂臂不偏 | 回应样本稀释跨源泛化 | 降回应占比 / 回应换源 |
| 触发率整体不足但不偏 | 敏感度/信噪比 | 加样本量 / 提质疑信噪比 |

### 3.4 探针分辨率自检（v0.2 补——对撞排出的第一死因）

无历史 AI 判"探针分辨率不足是本实验最大死因"（探针只查显性结构词→话术骗过→效度归零）。缓解合入：结构检测判分加"**结构与服务内容真匹配**"项（不只查词面有无结构，查结构里的内容是否真做了该做的事），与 §2 已知保守偏差声明叠加。试训准入门槛先证探针再谈其他——探针死了实验就死了，其他风险都有救。

**话术对照是第 0 步的灵魂**（B/C 双组后升级表述）：B 组涨=探针被格式骗；C 组涨=探针被调用记忆骗；两组都涨=判别力不成立。**只有 B、C 都不涨且试训组显著涨，才认定探针测的是行为不是话术。这一组对照直接实现 DS 训练池主选片段的判据："把批评转成验证动作"。**

## 4. 判定矩阵（预注册，先写后测）

| 探针结果 | 试训组 vs 双对照组（B/C） | 结论 | 后续动作 |
|---|---|---|---|
| 试训组涨 & B/C 组均不涨 | 差异显著 | **判别力成立** | v2-alpha 六项开工，第0步关闭 |
| B 组（话术对照）也涨 | 探针被格式骗 | **判别力不成立（格式维度）** | 探针重设计（结构检测升级为"结构-内容真匹配"判分）；蒸馏路线降级为"外挂+prompt 混合"主张 |
| C 组（换结局对照）也涨、B 组不涨 | 探针被调用记忆骗 | **判别力不成立（调用维度）** | 探针禁词令+题面升级（剔除可被明示调用匹配的句式），重设计后再一轮 |
| 两组都涨 | 双骗术全过 | **判别力全面不成立** | 探针重设计（行为链检测）+ 蒸馏主张降级混合终态 |
| 三组都不涨 | SFT 剂量不足或内化不可达 | 剂量加倍复测一次；仍不涨 → **权重内化主张判负**，接受混合终态（路由在外、直觉在内），七场结论"离散路由不适合权重形态"从假说升为定论 |
| 试训组涨但幅度 < 10pp | 判别力弱 | 探针可用但分级决策全压到中置信 | FDR 界限整体上调，迁移几乎不会发生——诚实结果，如实报告 |

**退出纪律**：判定矩阵四行预注册后，结果落在哪行就执行哪行，禁止事后重新解读（第 11 条原则：沉默也要付证据成本）。

## 5. 成本与顺序

```
第 0 步总计：3 骨架 × (40 探针输入构造[已完成 120 条] + 200-400 SFT 样本整理 + 3 组试训[试训/B/C] + 探针评测)
人工投入：探针输入抽查（用户，建议 6-8 条）+ 空转率盲评（用户每臂 30 条，约 1 小时）+ held-out 改写抽验 2 条 + 判定矩阵裁决（用户）
机器投入：9 次小规模 SFT（3 骨架×3 组，A/B 臂拆分另计）+ 探针推理批次——单卡日内级
顺序：素材账本（S1-S3 清点，关键路径起点）→ 三元组抽取 → 清洗去重 → 配方执行 → 对照组构造（与配方并行）→ 试训 → 探针评测 → 矩阵落点（用户终裁）
     → 通过 → 六项冻结清单按序开工（instrumentation 首任务）
     → 不通过 → 探针重设计后再一轮第 0 步（上限 2 轮，仍不通过则接受混合终态）
```

**配方卡 v0.2 沿革**：v0.1 = 设计咨询第 1 场轮 1-2（DS 联合设计者：视角分派/顶样本约束/偏科决策表/有效触发判据/held-out 三级校验）；v0.2 = 无历史 AI 独立配方对撞合入（伪纠错负例库/真实历史改题面+OOD/换结局 C 组/探针分辨率自检/扩写解禁降末位/3:1 收敛确认/Aa-Bc 配方空白补齐）。对撞分歧三处已逐个裁决：扩写 DS 立场过强（解禁但末位）、真实历史用法新 AI 对（题面+验证非正例）、对照组双组都要（骗术正交）。

## 6. 与冻结清单的关系

第 0 步不是第七项（不扩冻结清单——自锁条款双向），是**冻结清单第 1-6 项的共同前置**：探针判别力不成立，FDR/黄金集/TTL/双源全部没有意义。通过后第 0 步自身关闭，六项按原序开工。
