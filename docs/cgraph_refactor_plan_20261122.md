## 〇、#22 观测提醒（务必随本计划一起读）

> **当前仅 3 条历史样本，LLM 抽样校验受后端限速未执行。当前结论仅为定性现象，不是统计结论。环境恢复后必须扩充样本集（≥20 题）+ LLM 抽样校验复测，避免小样本偏差误导后续迭代。**

原假设「链路越长越发生累积式意图稀释」已被现有观测**推翻**：
- 贴合度高低主要由**节点本身职责定位**决定，非链路序号决定。
  - 方法论/元认知节点（G10 直觉锚定 / G11 内在怀疑 / G12 隐性共识 / G14 上下文等价校验 / G21 经验闭环）**天然字面相似度低**；
  - 内容扫描类节点（G00 任务空间扫描 / G09 逆向第一因 / G06 利益者全景）**天然字面相似度高**。
- 低分节点跨 3 样本稳定复现，且位置分布全链（第 2/5/7/9/12/14 位）→ 与链路位置无关。

## 一、任务修正固化

### #23 Router 分流强化（保留 P1，立项理由改写）

| | 内容 |
|---|---|
| ❌ 旧理由 | 解决链路变长带来的意图稀释 |
| ✅ 新理由 | **削减 LLM 调用次数，降低 12.6x 过高耗时**；修复 classify 识别不出 simple、medium 与 complex 路径无差别的现状 |
| 核心收益 | **性能层面**。不再指望分流「治跑偏」 |
| 要点 | classify 判准 simple；medium 真正裁短（当前与 complex 同 14 节点）；保留 MANDATORY_NODES 保底；分流结果写日志 |
| 风险 | 中。改路由核心，需回归验证三档路径确不同 + 质量不塌 |

### #24 Summary 推理核对表（保留 P1，机制目标改写）

| | 内容 |
|---|---|
| ❌ 旧定位 | 纠偏链路逐步跑偏、过滤无关输出 |
| ✅ 新定位 | **信息保真**：防止低字面贴合的方法论/元认知节点的有效思考价值被 final_answer 丢失/忽略 |
| 关键转变 | 核对表**不再用来筛掉低分节点**；强制审视「这些元认知产出有没有被合理引用到 final_answer」 |
| relevance 语义 | 不再简单等价「字面相似度高不高」，改为评估「该节点思考对回答问题有没有贡献价值」，**不能只看 embedding 余弦** |
| 前置依赖 | **推迟到 #23 交付后启动** |
| 风险 | 中高。需避免 LLM 自我美化，relevance 判定须独立于主链上下文 |

## 二、其余任务基线不变

- **#20 记忆系统可观测性 + 合规**：独立 P1 前置项，不受本次观测影响。
- **#25 Prompt 合并 / #26 异步归档 等性能任务**：逻辑不受影响。
- **Hebbian 三部曲（#17/#18/#19）**：预期依旧仅优化旁支，不改写主干。
