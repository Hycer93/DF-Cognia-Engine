# 记忆系统 vs 人脑：存取能力不足对照报告

> 生成时间：2026-11-23 22:43

## 一句话结论

系统在**"精确检索"和"不遗忘"**两个人脑的弱项上表现很强（D1 召回 5/5、永不丢失），
但在**"联想扩散、细节保真、时序叙事、主动遗忘、模式归纳"**这些人脑的强项上明显不足。
换句话说：**当前系统像一个"检索精准但不会联想的硬盘"，而不是"会遗忘、会归纳、会联想的大脑"。**

## 逐维分析

### D1 检索召回 —— 系统"强"，但只是精确命中

实测 5 个已知目标全部 top_k 召回。这说明 **ask() 的 DFCP编码+关键词+embedding 三路融合有效**。
但要区分两种"召回"：
- **人脑**：给一个模糊线索，能联想到**没直接匹配但相关**的记忆（扩散激活）
- **系统**：给关键词，召回**含该关键词/语义近**的卡（精确命中）

实测召回的都是"输入词在卡里出现"的，属于后者。**系统缺少"扩散联想"**——这点在 D3 更明显。

### D2 细节保真 —— 最大短板

- detail 平均 241 字、**p50 只有 100 字**、**115 张不到 100 字**、42 张干脆空
- 人脑回忆一件事能重构"当时场景、谁说了什么、什么情绪"
- 系统多数卡只剩 summary 一句 + 薄 detail，**做不了场景级重构**
- 根因：入库时 detail 本身就没存全（记忆卡是摘要制，不是录像制）

### D3 关联扩散 —— 几乎空白

- `entity_id` 只有 **3 张卡有值（0.85%）**，`core_entity_timeline` 仅 6 行
- `core_relation` 有 183 行（相对好些），但检索时**不做图遍历**，只做"同本体互斥去重"
- 人脑：提到"专利五"会自动带出"动态拓维""EWC""阈值自适应"一整片
- 系统：只能靠 summary 关键词碰巧同时出现，**主动关联链不存在**

这是**"第二大脑"最该补的能力**——知识的价值在连接，不在孤立存储。

### D4 时序记忆 —— 1/3 缺失

- event_ts（事件真实发生时间）覆盖 66.9%，117 张只有入库时刻（ts）
- 人脑有天然时间线（"这是去年冬天的事"）
- 系统对 1/3 的卡**只能知道"什么时候存进来的"，不知道"什么时候发生的"**
- 影响：`entity_evolution()` 的按时间线回忆，对缺 event_ts 的卡失效

### D5 遗忘曲线 —— 反直觉的"全留"

- tier 分布 active 315 / precedent 37 / weak-observ 1
- **没有自动衰减**：无 access_count、无老化扫描，降级全靠 `demote()` 手动触发
- 人脑：不重要的信息几天就淡忘，重要的反而越用越牢（重要性加权）
- 系统：**只增不减**，噪声卡永久占 active 位置，稀释检索信噪比
- 反直觉点：人脑的"遗忘"是特性不是缺陷；系统"全记住"看似强，实则**信噪比劣化**

### D6 冗余去重 —— 归纳缺失

- 353 卡有 **30 组重复 summary**（P24 专利 ×4、记忆断档 ×3、专利五推导 ×3...）
- P0 语义去重阈值 0.95 只在 on 模式拦截，且当前 dry-run；历史存量多版本并存
- 人脑：同一件事经历多次会**归纳成一条模式**（"哦这又是那类问题"）
- 系统：多版本并排躺着，靠人去归纳，**自己不会"举一反三"**

## 不足的根因归纳

| 表象 | 根因 | 可补方向 |
|---|---|---|
| 细节薄 | 摘要制入库，非全文录像 | 提高 detail 保真 / 挂原文引用 |
| 不联想 | entity 覆盖 0.85%，无图遍历 | 实体抽取+关系图+检索时扩散 |
| 时间乱 | event_ts 缺 1/3 | event_ts 回填（已有 82 条待办） |
| 不遗忘 | 无 access_count 老化 | 加访问计数+自动 demote 扫描 |
| 不归纳 | P0 只拦不全并 | 相似卡聚类归纳为模式卡 |
| 只精确不扩散 | ask 三路融合但无关联激活 | 关联图 + 半步扩散（查A带B）|

## 与人脑的本质差异（认知层）

1. **人脑是"重构式"记忆**：每次回忆是重新拼装，会失真但能灵活适配当前情境。
   **系统是"回放式"存储**：存什么取什么，不失真但不会适配。

2. **人脑遗忘=降噪**：忘掉次要的，保留重要的，信噪比随经验提升。
   **系统全留=噪声累积**：不遗忘导致旧噪声稀释新知识。

3. **人脑靠连接理解**：孤立事实很快遗忘，连成网才牢固。
   **系统靠独立索引**：每卡独立，连接需显式建（血缘/实体），当前覆盖极低。

> 结论：系统当前是**优秀的"外置硬盘"**，离**"认知伙伴"**还差"联想、遗忘、归纳"三块。
> 这三块恰好也是 LLM 判定卡（当前多处代码标注"LLM 卡上线后语义化"）要补的方向。
