## 三、采纳的核心缺口（仅 1 条真任务 + 2 个顺手项）

### 3.1 主任务：verify_ratio 消融实验（P1）

**问题**：Hebbian 边权更新绝大部分依赖 LLM 自判的 `verify_ratio`（`cgraph/hebbian.py`），存在**自循环漂移风险**，且"赫布边权调整是否真能改善路径选择"**从未证实或证伪**（全库无相关消融实验）。

**实验设计（多组对照）**：
- A 组：完整通路（verify_ratio 驱动边权）
- B 组：关闭 verify_ratio（边权不更新 / 仅结构路由）
- C 组：随机边权更新
- D 组：仅 external utility 信号（不依赖 LLM 自判）

**评估口径**：以路径选择质量（命中/盲评）为因变量，比较各组对路径分化与稳定性的贡献。

**产出**：`docs/review_21_verify_ratio_ablation_20261122.md`（实验设计 + 结果 + 结论），落 `eval/experiment/` 脚本，结果落 `logs/`。

### 3.2 顺手项①：A/B 结论沉淀（不新起任务）

已有 `ab_result_*.jsonl`（含 `question/bare/graph` 字段），只差一张汇总表：
- 跑 `eval/audit/score.py` 对已有结果盲评
- 汇总：图路由 vs 裸模型的**胜率 / 平均分 / 样本量 / 耗时比**

### 3.3 顺手项②：README 措辞校准（不算任务）

README 写"赫布路径进化 + 记忆驱动的经验闭环"，而 `hebbian.py` 自澄清是"带衰减权重计数器，无梯度无反向传播"。**叙事 > 现实**的落差，一改即消。
