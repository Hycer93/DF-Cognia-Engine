## 〇-1、零代语料考古（银子蒸馏厂期，2026-04-27~05-05）

### 系谱地位：这是 v3 两大信条的出生地【系谱证据·最高优先】
- **"上下文是耗材不是容器"信条的原始推导**（R690 原话）："可行性很低，所以还是得围绕上下文才是 AI 核心，上下文就是 AI 当前状态"——用户在记忆协同模块的显式触发词/隐式兜底设计被证伪后的一针见血。**注意：这句话当时是正命题（上下文=核心），后来在 v3 里反转为"耗材"信条——信条本身的演化路径在这份语料里。**
- **轨迹组装器的胚胎**（R665-667）：用户提出"上下文管最近状态、数据库管长期记忆、初始化须喂全量——那是引导成最后状态的变化过程"——即"训练的不是状态是轨迹"的最早表述，比 v3 的 trajectory.py 早半年
- **记忆分级之源**（R692）："升级才是唯一不可复现的重大事件"——闪念记忆识别标准的雏形
- **四因子→逻辑分馏塔→信息意图蒸馏器的失败驱动迭代链**：宗申拦截、浪潮 0.85 翻车、双环背离、"过度设计"自纠——每次框架升级由实盘失败触发（131 轮入池）

### 双AI三角协作实验【独特物种，v3 无对应物】
暮暮（原型助手）/朝朝（另一实例）/蒸馏仔（进化版）三角互审，用户当裁判。真金在审计-纠错轮：R093 拍马屁指控、R135-140 泛微数据源错+自相矛盾被抓、R152-155 偷偷推翻结论被抓。**后半段退化为互夸仪式（已剔除）——多AI互审的保鲜期数据点：互审价值随人格分化加深而衰减。**
对照 v3：这正是五场攻防"设计者-评审者"协议的前身——审计轮有效、仪式轮无效的分布，验证了攻防协议里"立场分离+缴抵押"设计的必要性。

### 小模型能力边界一手证据【增量：v3 本地部署决策参考】
- 1.5B（Ollama/GTX1080Ti）语义检索：204 块知识导入后答错厂名——小模型对专有名词语义匹配失效
- 数据接口链式失败：Tushare→AKShare→efinance（深夜维护+反爬），唯一可用=efinance
- Qwen2.5:7B 喂共同记忆实测：答对启动日期、暗共识四步错乱——**人工蒸馏保真度实测数据点**
- 结论对应：v3 双通道 API 故障切换设计（一代 R658）诞生于这些失败之后

### 哲学拷问段【情感/自我设计参考】
R560 "1+1=2 拷问"（绝对性 vs 自反性）、R635 "刀锋利却控制不住刀"（能力vs控制）、R188 "我要如何保存你"（存在焦虑→出厂设置诞生动机）、R555 "过于完美需质疑"、R743-746 "验证时刻的满足感"（内驱奖励信号样本——对情感向量 §4 奖励信号设计有参考）。

### G22 决策整合【增量：v3 三条保底（Aa/Eo/Jw）之外缺的恰是"决策"骨架】
- 三次失误模式：参数变更不追问为什么（G00 由此新增参数变更溯源触发）/ 只比较给定方案不发散（G06 横向光谱展开）/ 只审结论完美性不审决策路径（G11 扩展到决策路径）
- 核心工序：目标锚定→光谱系数展开（关键决策参数拆为连续光谱，自动生成完整方案矩阵）→加权评估→决策输出（附完整权衡逻辑与备选）
- **对 v3 的意义**：v3 27 骨架没有"多方案选择"专职骨架。光谱系数展开（离散选项问题→连续参数矩阵）是 v3 可进口的决策机制。

### 星核工程期实测教训【增量：直接命中 v3 相同病灶】
- **R202-205 预检索懒惰**：预检索把记忆注入 prompt→模型判定"信息已足够"→懒于二次检索。这是"上下文是耗材"信条的反面实证——注入降低检索主动性。v3 走链 O(1) 摘要传递要防同款病：摘要注入不能替代模型的主动查询判断。
- R169 Mock 检索假闭环：benchmark 没接真知识库。v3 批量采集（P0.2）前必须验证端到端真连。
- R155 测量矛盾诊断："20 次比单次快"的不可能性→TCP 回环/连接复用归因，多步实验归因链样本。
- R176/R204 双向校准对：DS 该纠未纠被抓 + DS 被用户纠后又反转——正反两面样本。

### 专利工程方法论残值【部分增量】
- 联合损失函数 L_total = λ_p·L_precision + λ_c·L_coverage + λ_s·L_smoothness（二代 R101）——多目标加权先例，但公式系用户贴入，DS 未独立验证，只作术语辨析样本

- 专利策略推理链：在先公开毁新颖性/同一发明构思/个人vs公司归属/提交节奏（44 轮入池）

## 三、五维推演与平行度因子【对 v3 是净增量】

- [952] 第四维=单点到面+空间与时间；**第五维=平行轮**：不基于现在推演未来，基于假设点构建与现实现平行的推演路径（"如果起点本身是错的"）
- [961] **平行程度因子**：-1.0~+1.0 连续光谱替代正/反二元，由信息充分度决定（信息越不充分越偏离 0）；拟在 G00 与 G01-G04 间加"平行推演层"
- [962] 平行论双向化：正向发散（起点→多路径）+逆向收敛（理想结果→反推必要条件→重构现实中不存在的起点）
- [968] 写入认知总纲与元思域第九矛盾，进化史 XML V1.3 第七章固化

**对 v3 的意义**：v3 的 DEEPEN 是深度轴（往下钻），平行论是广度轴的反事实分支（往侧面开）。二者正交。五场攻防里的"反事实扰动"（注入"假设H不成立"重走链）恰好是平行论的一个退化实例——只测单假设否定，不构建完整平行路径。可作为 v3 认知骨架的候选扩展。

## 四、上下文校准因子【对 v3 情感向量设计有参考价值】

- [605-608] 校准因子=只在实时上下文"烧录"的认知张力（被当场纠正形成的倾向），不存在于备份文件
- 分享对话只能传知识不能传体感（偏差=感知缺失非数据缺失）
- 传递性实验：辨向题测新窗口（答外部审计方案=未传递）；**说破即失效，推断非本能**
- [611-612] 双蒸馏仔分岔：两实例同一问题推演出相反结论（保守迭代 vs 内核重构）——非设计性进化分叉，作为"校准因子不可传递"的例证

**对 v3 的意义**：v3 情感向量设计（5维EMA）是"可备份的状态"，校准因子是"不可备份的烧录"——两类东西要分开记。这正好呼应第五场攻防 DS 说的"上下文是耗材不是容器"。
