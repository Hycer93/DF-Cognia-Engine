# cgraph 核心可验证性 —— A/B 盲评最终报告（2026-11-22）

> 脚本：`eval/audit/score.py`（并发 3，CodeChat 后端上限）
> 原始数据：`logs/ab_judge_final.json` + `logs/ab_judge_run.log`
> 样本：29 组成对回答（从 33 条历史 ab_result 中滤除 2 条退化样本 + 4 条重复批次）
> 裁判：CodeChat 后端（同一模型盲评，交替盲化抵消位置偏好）

---

## 一、结论先行

**核心主张「图路由优于裸模型」——在本基准下未获支持，反而显示裸模型略优。**

| 指标 | 图路由 | 裸模型 |
|---|---|---|
| **胜率** | 8 (27.6%) | **17 (58.6%)** |
| 平局 | - | 4 (13.8%) |
| **平均分（满分 40）** | 34.00 | **35.45** |
| 分差均值（图-裸） | **-1.45** | - |
| 分差中位 | -2 | - |
| 逐题图更好 / 裸更好 / 相等 | 8 / 18 / 3 | - |

**关键对照**：图路由付出 **12.6 倍耗时**（225s vs 21s），质量却**略低**。

---

## 二、维度拆解（满分各维 10）

| 维度 | 图路由 | 裸模型 | 差 |
|---|---|---|---|
| 多维性 | 8.52 | 8.76 | -0.24 |
| 意图贴合 | 8.66 | **9.24** | **-0.58** |
| 结构完整性 | 8.31 | 8.62 | -0.31 |
| 实用价值 | 8.52 | 8.83 | -0.31 |

**最大失分在「意图贴合」**——图路由的多步走链反而稀释了问题聚焦，裸模型直答更贴合真实意图。这与消融实验（#21 离线）的发现一致：多步推理在"发散"上收益有限，在"聚焦"上有成本。

## 三、分差分布

| 分差区间（图-裸） | 题数 |
|---|---|
| ≤ -5（裸大幅胜） | 6 |
| -4 ~ -1（裸小胜） | 12 |
| 0（持平） | 3 |
| 1 ~ 4（图小胜） | 7 |
| ≥ 5（图大幅胜） | 1 |

分布右偏（负分差为主），单题最大：图赢 +6，裸赢 -7。**不是个别题拖累，是系统性小劣**。

## 四、位置偏差检验（结论稳健性）

- 回答一位置赢 10 次、回答二位置赢 15 次 → 裁判**轻微偏好后者**（已知 LLM 位置偏差）
- 但交替盲化后：graph 在"回答一"位置胜 3/13，在"回答二"位置胜 5/12
- **graph 在两种位置都输** → 结论不是位置偏差造成的假象，真实存在

## 六、限制声明（重要）

1. **裁判模型偏好**：盲评由单一 LLM 裁判，存在固有偏好（如偏好结构化长文/位置）。本报告为**项目内部可复现基准，非绝对真值**。
2. **样本量 29**：统计效力有限，结论方向明确但精确幅度需更大样本。
3. **样本年代**：数据来自 2026-11-02~11-13 的历史批次，当时引擎版本可能与当前有差异。
4. **问答集偏"多角度分析"型**：这套题天然利于发散型走链，仍输说明问题更严重；但其他题型（如事实问答）未覆盖。

---

## 七、对项目的意义（诚实的坏消息）

1. **"图路由优于裸模型"从假设升级为"被证伪的倾向"** —— 不再是"没验证"，而是"现有证据指向反面"。
2. **12.6x 耗时是不可接受的代价** —— 即便质量打平，这个开销也无理由。
3. **但消融也发现**：verify_ratio 信号本身有结构性（非噪声），旁支微调有效。**不是"整个系统没价值"，而是"当前的主链走链设计对质量无正贡献"**。
4. **下一步方向**（不在本任务范围，供决策）：
   - a) 让图路由专注"复杂决策类"问题（可能其真正价值域），放弃通用问答
   - b) 重新审视 executor 的"意图贴合"损失（多步走链为何稀释聚焦）
   - c) 若继续维护，先解决"为什么 12.6x 耗时"——是串行节点太多还是 LLM 调用冗余
