## 0. 体系总览

主线：现状锚定 → 未来发散 → 分支赋权 → 正向演化 → 逆向倒推 → 结论聚合 → 落地精调，共六层，前缀 F 系（Future 推演系），与认知骨架 G 系（G00 发散层/G21 经验闭环/G22 决策整合）隔离，防图谱血统冲突。

| 层 | 名称 | 职能 | 输出 |
|---|---|---|---|
| F00 | 发散层·状态锚定 | 定义全局基准状态快照 | S_0 |
| F10 | 演化层·未来发散 | 由快照生成 K 条情景分支 | {B_k} |
| F20 | 权重层·分支赋权 | 评估各分支综合优先级 | W_k |
| F30 | 推演层·正向演化 | 分支沿演化规则推进到 T | S_T^(k) |
| F40 | 反推层·逆向收敛 | 由目标结局倒推粗解 | ΔX |
| F50 | 聚合层·结论聚合 | 只聚合结论向量，状态不平均 | 𝒴 + 原生分支清单 |
| F60 | 决策层·落地输出 | 正向演化校验逆向方案 | ΔX* |

核心范式：**倒推定位粗解 → 正演校验精调**（对标 MPC / 轨迹优化 / backplanning，主动声明同构）。
差异化主张：F00 状态从 DFCP 记忆 + 四维权重锚定（非传感器读数）；F20 价值项承接专利 P7 四维经验权重（频率/追问/关联/矛盾）。

## 1. F00 发散层——基准状态锚定

```
S_0 = {m_1, g_1, p_1, ..., m_n, g_n, p_n} = (E_0, I_0, U_0)
```

| 符号 | 定义 |
|---|---|
| S_0 | t_0 时刻全局基准状态快照 |
| m_n | 第 n 主体记忆惯性集合（历史决策/沉淀经验）——由 DFCP 检索供给 |
| g_n | 第 n 主体既定目标 |
| p_n | 第 n 主体约束、资源上限、固有边界 |
| E_0 | 内生主体状态块 {m_i,g_i,p_i} |
| I_0 | 外生环境向量（政策/市场/技术/冲击，不可控） |
| U_0 | 可控变量集合（本决策可调杠杆） |

**v2.1 补：主体特质块 p_trait**（恢复 r105 原版 p_n 性格语义）：
- 维度：行为倾向 / 决策偏好 / 风险承受度
- 位置：**不入 S_0 硬状态**，作为 F20 的 β 推荐基准输入（见 §3）

边界条件：有限维；t_0 一次性采集；缺失维度记 ∅ 不自动填充。

## 2. F10 演化层——未来发散

```
B(S_0) = {B_1, ..., B_K},  B_k = Φ_k(S_0; θ_k)
B_k = (S_0, P_k_路径, S_T^(k), C_k)
```

约束：**不要求分支互斥、不要求 ΣPr(C_k)=1**（v2 修复）；允许情景叠加共存（"技术突破"+"政策收紧"可同时生效）；只保证对决策高价值的联合情景组合被覆盖。

θ_k 扰动方向承接平行程度因子光谱（r961）：θ>0 好未来 / θ=0 中性 / θ<0 坏未来，为 [-1,+1] 连续光谱的分支级实现。

## 3. F20 权重层——分支赋权（v2.1 修订核心）

```
W_k = [Pr(C_k) · V_k · (1+δ_k)^β · Φ_penalty(k)] / Σ_j [Pr(C_j) · V_j · (1+δ_j)^β · Φ_penalty(j)]
```

| 项 | 定义 |
|---|---|
| Pr(C_k) | 情景组合先验联合概率 |
| V_k | 分支价值/损益权重（承接 P7 四维经验权重） |
| δ_k ≥ 0 | 相对基线偏差量；现状延续分支 δ=0 |
| β | 新颖偏好指数：β>1 探索 / 0<β<1 稳健 / β=0 关闭新颖调节 |
| Φ_penalty(k) | **v2.1 违规衰减罚分**（见下） |

**β 软约束（v2.1）**：p_trait 仅输出 β 的**推荐基准**（主体天然风险偏好暗示），不锁死——管线可脱离推荐自主探索，外部调用方可手动覆盖。理由：保留"推演风格是主体直觉延伸"的原始设计意图，又避免思考路线被固有性格固化。

**违规罚分（v2.1，替代原版 ∏σ 一票否决）**：
```
Φ_penalty(k) = γ^{v_k}   (0 < γ < 1, v_k = 分支 k 触碰约束的违规计数)
```
- 触约束分支打违规标签、权重大幅下调，但**完整保留在分支集合**中，可供复盘、思想推演查看
- 天然难成高权重主结论——抑制非法方案主导决策，但不抹除有启发的边缘假想
- 与库内"不删除只降权"哲学同构（topic hold 池 / fragile 卡降采信）

归一约束：ΣW_k = 1，W_k ≥ 0。

## 4. F30 推演层——正向演化

```
单步: S_{t+1} = F(S_t, A_t, I_t)
多步: S_T^(k) = Φ_k(S_0; θ_k)
```

非线性/分叉场景允许分支专属 F_k；推演路径允许提前收敛终止。

## 5. F40 反推层——逆向收敛倒推（粗解）

欠定系统通用正则版（现实场景多无解析逆）：
```
ΔX = argmin_{x∈X} ( ‖F⁻¹(G) − (S_0 + x)‖² + λ·Ω(x) )
```

| 符号 | 定义 |
|---|---|
| G | 预设目标终态 |
| F⁻¹ | 逆求解器（数值/搜索形式） |
| X | 可行调整空间，受 p_n 约束限定 |
| Ω(x) | 调整代价正则项（改动现状阻力/成本） |
| λ | 逼近-代价权衡；λ 越大越倾向小改动 |
| ‖·‖ | 加权欧氏 / 马氏距离 |

输出粗调方案 ΔX，只作候选，交 F60 正向校验。

## 6. F50 聚合层——结论聚合（v2 重大修订）

**禁止对状态 S_T^(k) 做加权平均**（防生成现实不存在的虚拟中间态；此缺陷在 r105 原版公式五即存在，v2 修复）。仅对可插值的抽象指标聚合：

```
𝒴 = Σ_{k=1}^{K} W_k · 𝒴_k
```

配套输出：①综合研判结论 𝒴；②按权重降序的全部原始分支（各自原生终态 S_T^(k)、前提、风险、违规标签）；③参考基线 = 最高权重分支的原生终态。

## 7. F60 决策层——落地输出

```
ΔX* = argmin_{x∈X} ( ‖F(S_0 + x, T) − G‖² + λ·Ω(x) )
```

用正向演化 F 重新验证候选调整：F40 逆映射快速给粗方向（低算力）→ F60 代入正演跑一遍校验修正（防逆求解失真）。倒推定位 → 正演验证双通道。
